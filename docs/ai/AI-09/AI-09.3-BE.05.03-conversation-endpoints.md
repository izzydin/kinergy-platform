## 1. Executive Summary

Task `AI-09.3-BE.05.03` implements and verifies the production REST endpoints for AI conversation management in `apps/api`. It connects the strongly typed, validated request DTOs from `BE.05.02` to the transactional application use cases implemented in `BE.04`. It ensures strict Clean Architecture compliance with zero business logic in controllers, zero Prisma leakage, authoritative tenant isolation through trusted authentication context, deterministic idempotent turn recovery, and full OpenAPI documentation.

### Core Architectural Guarantees:

1. **Zero Database / Prisma Leakage:** [AiConversationController](file:///c:/Projects/kinergy-platform/apps/api/src/ai/conversation/ai-conversation.controller.ts) contains zero direct database queries or Prisma imports. It delegates exclusively to application use cases.
2. **Authoritative Tenant & Actor Isolation:** Identity is derived exclusively from the verified server-side principal (`@TrustedAi()`). Client-supplied tenant or actor overrides in query or body parameters are strictly rejected.
3. **Idempotent Turn Recovery:** `POST /api/v1/ai/conversations` supports transparent idempotency. Re-submitting an identical `clientTurnId` and payload recovers the existing turn with `isIdempotentReplay: true` and `idempotencyOutcome: 'EXISTING_RECOVERED'`, without creating duplicate conversations or turns.
4. **Information Leakage Prevention:** All responses are transformed through [AiConversationResponseMapper](file:///c:/Projects/kinergy-platform/apps/api/src/ai/conversation/mappers/ai-conversation-response.mapper.ts), stripping internal payload hashes (`idempotencyPayloadHash`), lease tokens, transaction IDs, and internal audit logs.
5. **Real PostgreSQL Verification:** Relational integrity, composite tenant constraints, idempotent turn recovery, keyset pagination, and safe soft-archiving were validated against real PostgreSQL.

## 3. Detailed Endpoint Behaviors

### A. Create Conversation (`POST /api/v1/ai/conversations`)

- **Authentication:** Enforces active session/token with non-empty `actorId` and `tenantId`.
- **Validation:** Enforces `clientTurnId` (1..64 chars), non-blank `userPrompt` (1..4000 chars), optional `title` (1..255 chars), and optional object `metadata`.
- **Behavior:** Invokes `CreateConversationWithInitialTurnUseCase` to atomically create the conversation aggregate, initial turn, initial user message, and assistant placeholder within a database transaction.
- **Idempotency:** When the same `clientTurnId` is re-sent with matching payload, the existing conversation and turn are recovered, returning `201 Created` with `isIdempotentReplay: true` and `idempotencyOutcome: 'EXISTING_RECOVERED'`.
- **Conflict:** Re-using `clientTurnId` with a different payload throws `DuplicateClientTurnPayloadMismatchError` mapped to `409 Conflict`.

### B. List Conversations (`GET /api/v1/ai/conversations`)

- **Pagination:** Keyset pagination using base64url cursor `(lastActivityAt, id)`. Limit is bounded between `1` and `100` (default 20).
- **Tenant Scope:** Scoped authoritatively to `(tenantId, actorId)`. The client cannot query or observe another user's or tenant's conversations.
- **Soft Deletion:** Filtered by `deletedAt IS NULL` by default; soft-archived conversations are included only if `includeArchived=true`.

### C. Retrieve Conversation (`GET /api/v1/ai/conversations/:id`)

- **Scoping:** Scoped to the authenticated `tenantId`.
- **Output:** Returns conversation metadata, child turn summaries, and `activeTurnId`. Internal properties (`tenantId`, `userId`, internal DB IDs) are omitted from public serialization.
- **Inaccessible Resource:** If the conversation belongs to another tenant or does not exist, returns `404 Not Found` (`ConversationNotFoundError`), preventing tenant existence probing.

### D. Update Title (`PATCH /api/v1/ai/conversations/:id/title`)

- **Validation:** Requires non-blank string `title` (1..255 chars). Additional properties trigger `400 Bad Request` (`forbidNonWhitelisted: true`).
- **Scoping:** Scoped to `tenantId`. If archived or nonexistent, rejected with appropriate domain error.

### E. Archive Conversation (`DELETE /api/v1/ai/conversations/:id`)

- **Safe Soft Deletion:** Sets `deleted_at = NOW()`.
- **Safety Invariant:** Prohibited if an active assistant generation is in progress on any turn (`TurnAlreadyInProgressError` -> `409 Conflict`).
- **Audit Retention:** Preserves independent audit logs in PostgreSQL.

## 4. Error Mapping & HTTP Semantics

Exceptions are caught by [AiConversationExceptionFilter](file:///c:/Projects/kinergy-platform/apps/api/src/ai/conversation/filters/ai-conversation-exception.filter.ts) and mapped deterministically:

| Domain / Application Error                                                          | HTTP Status                 | Error Code                                                                 | Client Message                               |
| :---------------------------------------------------------------------------------- | :-------------------------- | :------------------------------------------------------------------------- | :------------------------------------------- |
| `ConversationNotFoundError` / `TurnNotFoundError` / `MessageNotFoundError`          | `404 Not Found`             | `AI_CONVERSATION_NOT_FOUND` / `AI_TURN_NOT_FOUND` / `AI_MESSAGE_NOT_FOUND` | Clean resource not found message             |
| `InvalidTurnInputError` / `InvalidCursorException` / `InvalidMessageOperationError` | `400 Bad Request`           | `AI_INVALID_TURN_INPUT` / `AI_INVALID_CURSOR` / `AI_BAD_REQUEST`           | Validation error message                     |
| `DuplicateClientTurnPayloadMismatchError`                                           | `409 Conflict`              | `AI_IDEMPOTENCY_PAYLOAD_MISMATCH`                                          | Idempotency payload mismatch description     |
| `TurnAlreadyInProgressError`                                                        | `409 Conflict`              | `AI_TURN_ALREADY_IN_PROGRESS`                                              | Generation already in progress               |
| `TenantOwnershipViolationError`                                                     | `403 Forbidden`             | `AI_TENANT_ACCESS_DENIED`                                                  | Tenant ownership violation message           |
| `TransientTransactionFailureError`                                                  | `503 Service Unavailable`   | `AI_SERVICE_TEMPORARILY_UNAVAILABLE`                                       | Transient lock failure; client retry advised |
| `TransactionFailureError`                                                           | `500 Internal Server Error` | `AI_PERSISTENCE_TRANSACTION_FAILURE`                                       | Stack trace redacted generic message         |
