> **Milestone:** AI-09.2.05  
> **Status:** BLOCKED / STOPPED (Mandatory Preflight Gate Triggered)  
> **Verdict:** REAL BACKEND STREAMING INFRASTRUCTURE MISSING — NO STREAMING SIMULATION  
> **Role:** Principal Frontend Architect & Senior Streaming Systems Engineer  
> **Target Subsystem:** `apps/web/src/modules/intelligence/assistant/` & `apps/api/src/ai/`  
> **Governing Standards:** Mandatory Preflight Audit (Section 1), ADR-AI-09-02 (Prohibition of Simulated Streaming), AI-09.2.00 Readiness Assessment

---

## Executive Summary

During the mandatory preflight phase of **AI-09.2.05**, a comprehensive technical audit of the full repository stack was executed across frontend and backend boundaries.

### Preflight Findings

1. **No Backend Streaming Controller:** `AiRAGController` (`apps/api/src/ai/controllers/ai-rag.controller.ts`) exposes only a synchronous, blocking HTTP POST endpoint (`POST /api/v1/ai/knowledge/query`). There are no `@Sse()` endpoints, no `text/event-stream` endpoints, and no WebSocket gateways.
2. **No Backend Streaming Use Case:** `IGenerateGroundedAnswerUseCase` (`packages/core/src/ai/ports/inbound/generate-grounded-answer.use-case.ts`) defines exclusively `execute(command): Promise<RAGAnswer>`. No streaming use case or reactive `Observable` / `AsyncIterable` port exists in the core domain or in `RAGOrchestratorService`.
3. **No Streaming Event DTOs:** No SSE or streaming event schemas or DTOs exist in `apps/api/src/ai/dto/` or `apps/api/src/ai/controllers/dtos/`.
4. **Governing Constraint Enforced:** In accordance with the prompt's explicit directive:
   > _"If the backend does not provide real streaming, do not simulate it. Report the missing backend dependency and stop this prompt."_
   > and **ADR-AI-09-02** (_"Simulated streaming is strictly prohibited; artificial delays or fake typing effects violate enterprise fidelity and accessibility guidelines"_), **frontend streaming integration cannot proceed without the real backend streaming contract in place**.

Execution is formally **stopped** at this preflight gate.

## 2. Technical Gap Analysis: Backend Streaming Architecture

The repository currently exhibits a architectural gap between the LLM adapter and the HTTP controller:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        Current Architecture                            │
└────────────────────────────────────────────────────────────────────────┘

[Frontend: Web Assistant]
        │
        │ HTTP POST /api/v1/ai/knowledge/query (Synchronous JSON)
        ▼
[AiRAGController] (apps/api/src/ai/controllers/ai-rag.controller.ts)
        │
        │ Promise<RAGAnswer> (Synchronous)
        ▼
[RAGOrchestratorService] (apps/api/src/ai/services/rag/rag-orchestrator.service.ts)
        │
        ├── 1. Vector Search (ISemanticSearchUseCase) ──> Synchronous Promise
        ├── 2. Context Builder (IRAGContextBuilderPort) ──> Synchronous String
        └── 3. LLM Generation (IGroundedGenerationPort) ──> Synchronous Promise
                    │
                    ▼
          [OllamaLlmAdapter]
          - generateAnswer(): Promise<string>  ◄── (Used by RAG)
          - generateStream(): AsyncIterable    ◄── (Unused by RAG & Controller)
```

### Missing Backend Components Required Before Frontend Streaming Can Be Implemented:

1. **Domain Use Case Port (`packages/core`):**
   - Inbound port `IGenerateGroundedAnswerStreamUseCase` or `executeStream()` method on `IGenerateGroundedAnswerUseCase` returning an `Observable<RAGStreamEvent>` or `AsyncIterable<RAGStreamEvent>`.
2. **Orchestrator Streaming Implementation (`apps/api`):**
   - `RAGOrchestratorService.executeStream()` that:
     - Emits a `phase: 'retrieval'` event.
     - Retrieves knowledge chunks and emits a `sources: RAGSourceCitationDto[]` event.
     - Emits a `phase: 'generation'` event.
     - Pipes `ollamaLlmAdapter.generateStream()` emitting `token: string` delta events.
     - Emits a final `complete: RAGMetadataDto` event with groundness verification and latency telemetry.
3. **HTTP Streaming Controller Endpoint (`apps/api`):**
   - `@Sse('knowledge/query/stream')` or `@Post('knowledge/query/stream')` in `AiRAGController` returning a NestJS `Observable<MessageEvent>` with `Content-Type: text/event-stream; charset=utf-8`.
4. **Verified Event DTOs (`apps/api`):**
   - Formally defined event contracts for:
     - `RAGPhaseEventDto`
     - `RAGSourcesEventDto`
     - `RAGTokenDeltaEventDto`
     - `RAGCompleteEventDto`
     - `RAGErrorEventDto`

## 3. Strict Compliance with Architecture Decision Records

### ADR-AI-09-02: Strict Prohibition of Simulated Streaming

> _"The frontend MUST NOT simulate streaming by artificially slicing completed text responses with `setInterval`, `setTimeout`, or client-side word buffering. Simulated streaming introduces artificial latency, degrades user experience for fast readers, breaks accessibility screen readers, and misrepresents system architecture."_

Because real streaming does not exist on the backend, creating client-side typing simulations or mock SSE streams would violate ADR-AI-09-02 and the explicit instructions of this milestone.

---

## 4. Current Operational Behavior (AI-09.2.04 Verified Baseline)

The frontend conversational interface remains fully functional, robust, and production-ready in its verified non-streaming state:

1. **User Prompt Submission:** Validated (3..1000 characters) and locked against duplicate submissions via mutex.
2. **Deterministic Phased State:** While the synchronous request is in flight, `ChatMessageItem` displays an animated progress indicator:
   - _"Sintetizando respuesta fundamentada..."_
3. **Atomic Response Reconciliation:** Upon HTTP 200 resolution, the complete answer Markdown, verified citations tray, and performance telemetry (`latencyMs`, `model`, `grounded`) are rendered atomically.
4. **Draft Preservation:** On any failure (4xx, 5xx, timeout, network error), the prompt draft remains in the composer textarea.
5. **Request Cancellation:** The user can abort in-flight requests at any time via `AbortController`.

## 5. Required Action Items to Unblock AI-09.2.05

To unblock real-time streaming integration:

1. **Backend Milestone AI-08.X:** Implement SSE streaming endpoint `POST /api/v1/ai/knowledge/query/stream` in `AiRAGController` with typed event schemas (`phase`, `sources`, `token`, `complete`, `error`).
2. **Backend Verification:** Add integration tests verifying token chunk emission and citation verification over Server-Sent Events.
3. **Resume AI-09.2.05:** Once the backend streaming contract is merged and active, implement `AssistantStreamTransport` (using fetch-based `ReadableStream` reader with JWT authorization headers), connect to `useGenerationLifecycle` via `STREAM_START`, and progressively update the active assistant message turn in the UI.
