# AI-09.10 — IT.05: Citation, Source Authorization, and Security Tests

## Overview & Scope

The **IT.05** milestone establishes rigorous, evidence-based integration and security testing for Kynergy Intelligence citations and document previews. It verifies that:

1. Citations rendered across user interfaces are strictly grounded in verified retrieval metadata from the backend (no fabricated titles, chunks, pages, or phantom citations).
2. Citation references adhere to relational integrity constraints (citation-to-message, message-to-turn, turn-to-conversation) with document version pinning.
3. Multi-tenant boundaries and role-based access control (RBAC) are strictly enforced at the backend persistence and use-case layer (IDOR protection, scope clearance, short-lived HMAC preview tokens).
4. Interactive preview lifecycle states (`DOCUMENT_AVAILABLE`, `DOCUMENT_RESTRICTED`, `DOCUMENT_SOFT_DELETED`, `EXCERPT_ONLY`, `UNSUPPORTED_FORMAT`) are handled deterministically without leaking restricted content.
5. Frontend cache boundaries prevent cross-user leakage (cache clearing on logout, cancellation of in-flight queries).
6. Security hardening guarantees immunity against XSS injection vectors in document titles and excerpts, and prevents information leakage (stack traces, SQL, object storage keys) on failure.

## Security Verification Summary

1. **IDOR & Multi-Tenancy**: Guaranteed at both query level (`tenantId` WHERE clauses) and use-case authorization guards. Cross-tenant access attempts fail with 403 or 404 without leaking document existence.
2. **Cryptographic Token Integrity**: Preview tokens use HMAC-SHA256 signatures with 15-minute expiration windows. Any modification of user ID, document ID, version, or timestamp immediately invalidates the signature.
3. **Auditability & Traceability**: Even if a source document is archived or deleted from storage, the citation relation, snippet, and version snapshot remain intact in `ai_conversation_citations` for compliance and clinical auditability.
4. **Cache & Memory Hygiene**: Frontend cache keys include user and tenant boundaries; complete cache clearing on authentication state change eliminates shared terminal risks.
