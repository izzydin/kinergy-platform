## 4. Implementation Boundary for Milestone AI-09.1

Strict scope boundaries are established to avoid premature feature implementation during this foundation milestone:

### Within Scope for AI-09.1

1. **Module Scaffolding:**
   - Create `apps/web/src/modules/intelligence/` directory tree.
   - Create public module entrypoint `index.ts`.
2. **API Client & Query Foundation:**
   - Implement `api/intelligence-api.client.ts` wrapping shared `httpClient`.
   - Implement `api/query-keys.ts` defining structured query key factories.
   - Implement `api/health.api.ts` calling `GET /api/v1/ai/health`.
3. **Route Registration & Guards:**
   - Define module routing contract in `routes/intelligence.routes.tsx`.
   - Register `/intelligence` prefix in `moduleRegistry`.
   - Implement placeholder page components:
     - `ChatPage` (`/intelligence/chat`, `/intelligence/chat/:conversationId`).
     - `KnowledgePage` (`/intelligence/knowledge`).
     - `DocumentDetailPage` (`/intelligence/knowledge/documents/:documentId`).
   - Wrap routes with `ProtectedRoute` and `RequirePermission`.
4. **Navigation Framework Integration:**
   - Register "Kynergy Intelligence" navigation items in `navigationRegistry`:
     - Chat Asistente (`/intelligence/chat`, Icon: `Bot`).
     - Base de Conocimiento (`/intelligence/knowledge`, Icon: `BookOpen`).
5. **Shared Intelligence Layout & Viewport Shell:**
   - Implement `components/shared/intelligence-layout.tsx` providing a fixed 100vh viewport container with top sub-navigation tabs (Chat vs Knowledge).
   - Implement `components/shared/ai-health-pill.tsx` in page header displaying live subsystem status.
6. **Error & Loading Boundaries:**
   - Implement module-level `IntelligenceErrorBoundary` and loading skeleton view.
7. **Verification Testing:**
   - Unit tests for route registration, navigation items, health API client, and layout rendering.

### Strictly Out of Scope for AI-09.1 (Deferred to Later Milestones)

- ❌ Chat messaging, prompt submission, or conversation turns (`AI-09.3`).
- ❌ LLM API query execution (`AI-09.3`).
- ❌ Message composer and markdown syntax highlighting (`AI-09.3` / `AI-09.4`).
- ❌ Conversation history localStorage persistence (`AI-09.3`).
- ❌ Citation chip rendering and drawer popovers (`AI-09.4`).
- ❌ Document drag-and-drop file upload (`AI-09.2`).
- ❌ Ingestion polling and state machine steppers (`AI-09.2`).
- ❌ Any backend modifications or mock services.
