## 1. Executive Summary

Milestone **AI-10.2-06** ensures that document versions, citations, excerpts, and source previews cannot be leveraged to bypass document ownership, tenant isolation, or role-based clearance boundaries.

During this milestone:

1. **Audited & Hardened Document Version Endpoints:** Verified that every document version is accessed strictly via its authoritative parent document `(tenantId, documentId, versionId)`. Prevented direct version lookup solely by guessing or knowing a `versionId`.
2. **Eliminated Information Disclosure in Preview Metadata:** Remediated a potential metadata leakage vulnerability in `AiDocumentController.getPreviewMetadata` where unauthorized callers could previously receive document titles, original filenames, checksums, and file sizes. The endpoint now enforces strict role clearance and uniform fail-closed `ForbiddenException` (403) before any metadata is computed or returned.
3. **Verified Citation Access & Dynamic Re-Evaluation:** Citations maintain snapshot integrity (`documentTitleSnapshot`, `excerpt`, `headingPath`) for historical auditability within conversations, but dynamically re-evaluate caller authorization and document lifecycle state upon every retrieval. If a source document has its visibility scope restricted or is soft-deleted, subsequent preview requests immediately transition to `DOCUMENT_RESTRICTED` or `DOCUMENT_SOFT_DELETED`, revoking preview tokens and blocking binary content downloads.
4. **Cryptographic Preview Token Verification:** Verified that `PreviewTokenService` generates HMAC SHA-256 signed, short-lived (5-minute TTL) tokens strictly scoped to `{ tenantId, userId, conversationId, messageId, citationId, documentId }`. Tokens cannot be reused across tenants, conversations, messages, or documents, and tamper attempts fail closed via constant-time signature comparison (`crypto.timingSafeEqual`).
5. **Implemented Full 10-Scenario Verification Suite:** Authored and verified `ai-version-citation-authorization.integration.spec.ts` covering all required security scenarios with a 100% pass rate (11/11 tests passing in 8.4s), alongside existing unit and PostgreSQL integration suites.

## 3. Implementation Hardening & Component Walkthrough

### 3.1. Remediation of `AiDocumentController.getPreviewMetadata`

**Location:** `apps/api/src/ai/controllers/ai-document.controller.ts#L834-L885`

**Issue Identified:** Previously, when a caller lacked the necessary role clearance (`isAuthorized === false`), the method returned an HTTP 200 payload with `isAuthorized: false, canPreview: false`, but inadvertently included sensitive document metadata: `title`, `originalFileName`, `checksum`, and `fileSize`.

**Remediation Applied:**

```typescript
let isAuthorized = doc.visibilityScope === VisibilityScope.ALL_STAFF;
if (this.securityPolicy && user?.roles && user.roles.length > 0) {
  const allowedScopes = this.securityPolicy.resolveAllowedVisibilityScopes(user.roles);
  isAuthorized = allowedScopes.includes(doc.visibilityScope);
}

if (!isAuthorized) {
  throw new ForbiddenException(
    'You do not have the required role clearance to access or preview this document.',
  );
}
```

Unauthorized callers now receive an immediate 403 Forbidden response with zero document metadata, original filenames, or checksums exposed.

### 3.2. Citation Use Case & Streaming Authorization

**Location:** `packages/core/src/ai/application/use-cases/`

- `GetCitationPreviewUseCase.execute()`: Validates conversation tenant and user ownership, message association, citation binding, document existence, soft-deletion status, and role-based visibility. If unauthorized, assigns `DOCUMENT_RESTRICTED` or `DOCUMENT_SOFT_DELETED`, setting `canPreview = false` and denying download capabilities.
- `GetCitationDocumentStreamUseCase.execute()`: Re-evaluates live document clearance and soft-deletion status on every binary streaming request. Prevents silent drift between versions by strictly matching `citation.documentVersionId`. Rejects unauthorized or soft-deleted requests with `DocumentAccessRestrictedError` or `DocumentArchivedOrDeletedError`.
- `AiConversationController.getCitationPreview()`: Issues short-lived preview tokens only when `canPreview === true`.
- `AiConversationController.getCitationDocumentContent()`: Validates incoming tokens via `PreviewTokenService` or enforces Bearer JWT claims, verifying tenant boundary, conversation ownership, role clearance, and previewable MIME types (`application/pdf`, `text/plain`, `text/markdown`, `text/csv`, `application/json`).

## 6. Residual Risk Assessment & Operational Guidance

1. **Preview Token Secret Rotation:** The `AI_PREVIEW_TOKEN_SECRET` environment variable must be configured in production with at least 32 characters of high-entropy randomness. In case of secret rotation, active preview tokens will expire within their 5-minute window; frontend clients will seamlessly acquire fresh tokens via citation preview requests.
2. **Object Storage Pre-Signed URLs vs Proxied Streaming:** File streaming is proxied through `AiConversationController.getCitationDocumentContent` and `AiDocumentController.downloadContent`, enabling real-time authorization checks and preventing direct cloud storage URL tampering or enumeration.
3. **Audit Trail Retention:** Deletion of knowledge documents retains citation records in `AiConversationCitation` to ensure medical and clinical audit trails remain intact while strictly preventing preview or re-download.
