## 2. Image Selection & Provenance

### 2.1 Evaluated Candidate Images

1. **`postgres:16-alpine` (Previous Baseline):**
   - Lacks compiled `vector.so` and `vector.control`. Requires manual multi-stage compilation involving Alpine build dependencies (`build-base`, `clang`, `llvm16`), introducing unapproved build maintenance overhead.
2. **`pgvector/pgvector:pg16` (Approved Candidate):**
   - Official image maintained by the `pgvector` team.
   - Built on official PostgreSQL 16 Debian Bookworm.
   - Pinned Digest: `sha256:484e838076e04939d27d3e176e91c86eea96236126023be8d3059761122e579f`
   - Image ID: `484e838076e0`
   - Includes `pgvector` v0.8.7 pre-compiled with HNSW, IVFFlat, halfvec, and sparse vector support.
