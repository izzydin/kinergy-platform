# AI-09.4-CIT.04 — Citation Rendering Components Implementation Report

## Executive Summary

The **CIT.04** milestone delivers the frontend citation-rendering architecture for Kynergy Intelligence (`apps/web`). It connects the verified RAG retrieval provenance persisted by CIT.02 and CIT.03 to an accessible, interactive, and responsive user interface within assistant conversation messages.

Citations are rendered as numbered reference badges `[1]`, `[2]`, etc. at the bottom of the relevant assistant message, matching backend retrieval ranking. Clicking a badge opens the comprehensive `CitationDetailDialog`, exposing the full un-truncated excerpt, page and section references, relevance scoring, and preview status banners (handling soft-deleted or role-restricted documents gracefully). No citation data is derived by parsing arbitrary assistant prose, and no citations are shown when an assistant response has no verified provenance.

## 2. Component Design & Responsibilities

### 2.1 `CitationBadge`

- **File:** [citation-badge.tsx](file:///c:/Projects/kinergy-platform/apps/web/src/modules/intelligence/assistant/components/citation-badge.tsx)
- **Role:** Interactive pill representing an individual source reference.
- **Key Behaviors:**
  - Strict 1-based index numbering `[index + 1]` matching backend retrieval rank.
  - Responsive truncation of long titles (`max-w-[120px] sm:max-w-[160px] md:max-w-[200px] truncate`).
  - Page chip (`p.X`) rendered only when available from backend provenance.
  - Visual status indicator: `Archive` icon for soft-deleted documents, `ShieldAlert` for restricted documents, `FileText` for standard documents.
  - Fully keyboard-accessible via `Enter` or `Space` keypresses and explicit focus rings (`focus-visible:ring-1 focus-visible:ring-primary`).

### 2.2 `CitationDetailDialog`

- **File:** [citation-detail-dialog.tsx](file:///c:/Projects/kinergy-platform/apps/web/src/modules/intelligence/assistant/components/citation-detail-dialog.tsx)
- **Role:** Modal dialog presenting complete citation provenance and preview status.
- **Key Behaviors:**
  - Displays full un-truncated `excerpt` inside a styled blockquote (`select-text`, `whitespace-pre-wrap`).
  - Renders section hierarchy outline (`headingPath`) when available.
  - Displays relevance percentage (e.g. `95% de relevancia`) and retrieval rank (`Rango #1`).
  - Seamlessly handles soft-deleted documents (`DOCUMENT_SOFT_DELETED`) and role-restricted documents (`DOCUMENT_RESTRICTED`), displaying informative alert banners without breaking dialog rendering or dropping historical evidence.
  - Provides a direct link to the original document (`/api/v1/ai/knowledge/documents/:documentId/content`) only when authorized (`canPreview === true && previewStatus === 'DOCUMENT_AVAILABLE'`).
  - Automatically fetches enriched remote metadata via `useCitationDetail` query hook if `citationId` is provided, with graceful fallback to message snapshot props.

### 2.3 `MessageCitations`

- **File:** [message-citations.tsx](file:///c:/Projects/kinergy-platform/apps/web/src/modules/intelligence/assistant/components/message-citations.tsx)
- **Role:** Tray container embedded at the foot of successful assistant responses.
- **Key Behaviors:**
  - Renders `null` if `sources` is empty or undefined (never renders empty border boxes).
  - Maintains active citation selection and dialog state.
  - Passes conversation and message context to `CitationDetailDialog`.
