## 3. Database Objects Verified

### 3.1 Tables & Enums

- **Tables:** `ai_conversations`, `ai_conversation_turns`, `ai_conversation_messages`, `ai_conversation_audit_logs`.
- **Enums:** `ConversationRole` (`USER`, `ASSISTANT`, `SYSTEM`), `GenerationStatus` (`PENDING`, `STREAMING`, `SUCCESS`, `FAILED`, `CANCELLED`, `INTERRUPTED`), `TurnStatus` (`PENDING`, `STREAMING`, `COMPLETED`, `FAILED`, `CANCELLED`, `INTERRUPTED`).

### 3.2 Composite Foreign Keys

1. `ai_conversation_turns_conversation_id_tenant_id_fkey`: `(conversation_id, tenant_id) REFERENCES ai_conversations(id, tenant_id) ON DELETE CASCADE`
2. `ai_conversation_messages_conversation_id_tenant_id_fkey`: `(conversation_id, tenant_id) REFERENCES ai_conversations(id, tenant_id) ON DELETE CASCADE`
3. `ai_conversation_messages_turn_id_conversation_id_tenant_id_fkey`: `(turn_id, conversation_id, tenant_id) REFERENCES ai_conversation_turns(id, conversation_id, tenant_id) ON DELETE CASCADE`
4. `ai_conversation_turns_active_attempt_id_fkey`: `(active_attempt_id) REFERENCES ai_conversation_messages(id) ON DELETE SET NULL`

### 3.3 Partial Unique Indexes

1. `ai_conversation_active_generation_idx`: `ON ai_conversation_messages(conversation_id) WHERE role = 'ASSISTANT' AND status IN ('PENDING', 'STREAMING')`
2. `uq_turn_single_user_message`: `ON ai_conversation_messages(turn_id) WHERE role = 'USER'`
3. `uq_turn_single_canonical_assistant`: `ON ai_conversation_messages(turn_id) WHERE role = 'ASSISTANT' AND is_canonical = TRUE`

### 3.4 Check Constraints

- `chk_canonical_requires_success`: `"is_canonical" = FALSE OR ("role" = 'ASSISTANT' AND "status" = 'SUCCESS')`
- `chk_terminal_attempt_no_active_lease`: Terminal states cannot retain active lease tokens or expiration dates.
- `chk_turn_index_positive`: `"turn_index" >= 1`
- `chk_active_attempt_number_positive`: `"active_attempt_number" >= 1`
- `chk_sequence_number_positive`: `"sequence_number" >= 1`
- `chk_attempt_number_positive`: `"attempt_number" >= 1`

### 3.5 PostgreSQL Triggers

1. **`trg_validate_turn_active_attempt`:** Deferrable constraint trigger (`DEFERRABLE INITIALLY DEFERRED`) verifying that any `active_attempt_id` belongs to an assistant message in the same turn, conversation, and tenant.
2. **`trg_protect_message_immutability`:** `BEFORE UPDATE` trigger preventing changes to `role`, `turn_id`, `conversation_id`, or `tenant_id` on existing messages.

## 4. Test Methodology & Verification Results

Verification was performed by `apps/api/src/ai/__tests__/ai-conversation-database.integration.spec.ts`.

### 4.1 Concurrency Testing Methodology

- **Multi-Connection Harness:** Two independent `PrismaClient` instances (`clientA` and `clientB`) establish distinct physical PostgreSQL server backends.
- **Synchronization Barrier:** Competing operations are launched concurrently using `Promise.allSettled()`.
- **Database Outcome Assertion:** Confirms that exactly one competing transaction commits successfully, while the competing transaction is rejected with PostgreSQL code `23505` (`unique_violation`).
