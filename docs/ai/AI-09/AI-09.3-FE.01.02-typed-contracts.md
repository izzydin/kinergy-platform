## 1. Executive Summary

Milestone **FE.01.02** establishes the strongly typed, validated frontend contract boundary for the Kynergy AI conversation subsystem, implementing the backend-to-frontend mapping verified in milestone **FE.01.01** ([AI-09.3-FE.01.01-backend-contract-mapping.md](file:///c:/Projects/kinergy-platform/docs/ai/AI-09/AI-09.3-FE.01.01-backend-contract-mapping.md)).

Prior to this milestone, frontend chat operations relied on legacy AI-09.2 stateless knowledge query types and client-side partitioned browser storage. With the completion of FE.01.02:

1. **Strongly Typed Request & Response Interfaces:** Comprehensive TypeScript contracts model every verified AI-09.3 endpoint (`CreateConversation`, `ReserveTurn`, `CancelTurn`, `GetConversation`, `ListConversations`, `GetMessageHistory`, `UpdateTitle`, `ArchiveConversation`, `AuditInspect`), maintaining exact alignment with backend DTOs without inventing optional fields or exposing server-only internals.
2. **Runtime Zod Validation Boundary:** Robust Zod schemas guard against API contract drift, validating status enums, UUID/CUID identifiers, monotonic positive sequence numbers, citation relevance scores in `[0, 1]`, and keyset pagination cursor envelopes.
3. **Pure Status Mapping Adapter:** An independently testable adapter translates backend `TurnStatus` (`PENDING`, `STREAMING`, `COMPLETED`, `FAILED`, `CANCELLED`, `INTERRUPTED`) and assistant message `GenerationStatus` (`PENDING`, `STREAMING`, `SUCCESS`, `FAILED`, `CANCELLED`, `INTERRUPTED`) into the existing AI-09.2 frontend generation FSM (`IDLE`, `PENDING`, `STREAMING`, `COMPLETED`, `FAILED`, `CANCELLED`, `INTERRUPTED`). Crucially, backend message `SUCCESS` maps cleanly to frontend `COMPLETED`, and no `RECOVERING` status is introduced.
4. **Zero Regressions on Legacy UI Components:** Canonical backend message responses adapt cleanly to domain `ChatMessage` objects, preserving 100% compatibility with existing rendering components (`ChatMessageFeed`, `ChatMessageItem`, `AssistantMessage`).
5. **Quality Gates Cleared:** All 10 assistant test suites (106 tests total, including 22 new contract tests) pass with 100% success rate, monorepo typecheck (`tsc --noEmit`) passes with 0 errors, ESLint passes with 0 warnings, and `web:build:production` builds cleanly.

## 4. Status Mapping & Adapter Implementation

Implemented in `apps/web/src/modules/intelligence/assistant/adapters/conversation-status.adapter.ts`:

### 4.1 Backend Status to Frontend FSM Mapping

```typescript
// 1. TurnStatus to GenerationStatus FSM
export function mapBackendTurnStatusToFsm(turnStatus: BackendTurnStatus): GenerationStatus {
  switch (turnStatus) {
    case 'PENDING':
      return 'PENDING';
    case 'STREAMING':
      return 'STREAMING';
    case 'COMPLETED':
      return 'COMPLETED';
    case 'FAILED':
      return 'FAILED';
    case 'CANCELLED':
      return 'CANCELLED';
    case 'INTERRUPTED':
      return 'INTERRUPTED';
  }
}

// 2. Assistant Message GenerationStatus to GenerationStatus FSM
export function mapBackendMessageStatusToFsm(
  generationStatus: BackendGenerationStatus,
): GenerationStatus {
  switch (generationStatus) {
    case 'PENDING':
      return 'PENDING';
    case 'STREAMING':
      return 'STREAMING';
    case 'SUCCESS':
      return 'COMPLETED'; // Maps canonical assistant completion to frontend FSM
    case 'FAILED':
      return 'FAILED';
    case 'CANCELLED':
      return 'CANCELLED';
    case 'INTERRUPTED':
      return 'INTERRUPTED';
  }
}
```

### 4.2 State Rehydration on Reconnect / Refresh

```typescript
export function reconcileConversationViewState(params: {
  activeTurnId?: string | null;
  activeTurnStatus?: BackendTurnStatus | null;
  isSubmitting?: boolean;
}): GenerationStatus {
  if (params.isSubmitting) return 'PENDING';
  if (!params.activeTurnId || !params.activeTurnStatus) return 'IDLE';

  switch (params.activeTurnStatus) {
    case 'PENDING':
      return 'PENDING';
    case 'STREAMING':
      return 'STREAMING';
    case 'COMPLETED':
    case 'FAILED':
    case 'CANCELLED':
    case 'INTERRUPTED':
      return 'IDLE'; // Conversation is quiescent; composer is ready for next input
  }
}
```

### 4.3 Domain ChatMessage Adaptation for UI Compatibility

```typescript
export function toDomainChatMessage(msg: MessageResponse): ChatMessage {
  return {
    id: msg.id,
    role: mapBackendRoleToLegacy(msg.role), // 'USER' -> 'user', etc.
    content: msg.content,
    createdAt: msg.createdAt,
    status: mapBackendMessageStatusToLegacy(msg.status), // 'SUCCESS' -> 'success', etc.
    grounded: Boolean(msg.sources && msg.sources.length > 0),
    sources: msg.sources?.map((s) => ({
      documentId: s.documentId,
      documentTitle: s.documentTitle,
      chunkId: s.chunkId,
      pageNumber: s.pageNumber ?? undefined,
      headingPath: s.headingPath ?? undefined,
      relevanceScore: s.relevanceScore,
      sourceStrategy: s.sourceStrategy ?? undefined,
    })),
  };
}
```
