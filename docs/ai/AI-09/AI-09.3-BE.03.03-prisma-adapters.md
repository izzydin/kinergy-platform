  - `softDelete(tenantId, id)`: Sets `deletedAt: new Date()` within tenant boundary.
  - `hardDelete(tenantId, id)`: Deletes conversation; cascaded PostgreSQL foreign keys delete turns and messages while audit logs persist independently.
  - `withTransaction(tx)`: Creates a scoped repository instance sharing an active transaction context.

### Diagnostic Context & Reconstitution Safety

If persisted data in the database cannot be reconstructed into a valid domain entity (e.g. malformed UUID, missing required fields, or unmapped enums), mappers do not silently swallow or mutate the data. Instead, they catch the domain validation error and throw a `ConversationPersistenceException` containing the record ID and failure reason, strictly avoiding logging raw user prompts or assistant answers.

## 4. Tenant Isolation Strategy

Tenant scoping is unconditionally enforced at both the application adapter layer and the database layer:

1. **Application Layer:** Every query across all four repository adapters includes `tenantId` in its Prisma `where` clause (e.g. `where: { id: idStr, tenantId }`). Unscoped queries like `findUnique({ where: { id } })` are strictly prohibited.
2. **Database Layer:** Authoritatively verified by PostgreSQL composite foreign keys:
   - `(conversation_id, tenant_id) REFERENCES ai_conversations(id, tenant_id) ON DELETE CASCADE`
   - `(turn_id, conversation_id, tenant_id) REFERENCES ai_conversation_turns(id, conversation_id, tenant_id) ON DELETE CASCADE`

## 5. Keyset Pagination Implementation

### 5.1 Message History Keyset Pagination

- **Ordering:** `(sequenceNumber ASC, id ASC)`.
- **Query Filter:** `OR: [{ role: 'USER' }, { isCanonical: true }]`.
- **Cursor Condition:**
  ```prisma
  OR: [
    { sequenceNumber: { gt: cursor.sequenceNumber } },
    { sequenceNumber: cursor.sequenceNumber, id: { gt: cursor.messageId } }
  ]
  ```
- **Snapshot Consistency:** **Guaranteed**. Because sequence numbers are immutable and monotonically increasing, traversal results remain completely consistent during concurrent active turns.

### 5.2 Conversation Listing Pagination

- **Ordering:** `(lastActivityAt DESC, id DESC)`.
- **Cursor Condition:**
  ```prisma
  OR: [
    { lastActivityAt: { lt: cursor.lastActivityAt } },
    { lastActivityAt: cursor.lastActivityAt, id: { lt: cursor.conversationId } }
  ]
  ```
- **Mutable Activity Limitation:** Explicitly documented in contract: because `lastActivityAt` updates upon each new message, active conversations may shift positions across pages.

### 5.3 Audit History Keyset Pagination

- **Ordering:** `(createdAt DESC, id DESC)`.
- **Cursor Condition:**
  ```prisma
  OR: [
    { createdAt: { lt: cursor.createdAt } },
    { createdAt: cursor.createdAt, id: { lt: cursor.auditId } }
  ]
  ```
- **Independent Retention:** Audit records are queried directly from `ai_conversation_audit_logs` without joining conversations. Even after a conversation is hard deleted, its audit logs remain intact and fully paginatable.

## 6. Transaction-Client Compatibility

- All repository constructors accept `PrismaClient | Prisma.TransactionClient`.
- Each repository implements `.withTransaction(tx: Prisma.TransactionClient): ThisClass`, returning an adapter instance bound to the active transaction.
- Repositories never independently initiate, commit, or abort transactions, leaving transaction lifecycle orchestration completely to future application use cases.

## 7. Infrastructure Error Translation

Source: [prisma-persistence-error.handler.ts](file:///c:/Projects/kinergy-platform/packages/core/src/ai/infrastructure/persistence/prisma/prisma-persistence-error.handler.ts)

| Prisma Error Code   | Database Condition                                                         | Translated Domain Exception                                                             |
| :------------------ | :------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------- |
| **`P2002`**         | Unique constraint violation (e.g. idempotency, turn index, client turn ID) | `DuplicateEntityException(entity, target, tenantId)`                                    |
| **`P2025`**         | Target record not found for update, delete, or lookup                      | `ConversationNotFoundException`, `TurnNotFoundException`, or `MessageNotFoundException` |
| **`P2003`**         | Foreign key constraint violation (cross-tenant or orphaned turn)           | `InvalidOwnershipException`                                                             |
| **Other / Generic** | Connection failure, query execution error                                  | `ConversationPersistenceException` (preserving cause without leaking sensitive data)    |
