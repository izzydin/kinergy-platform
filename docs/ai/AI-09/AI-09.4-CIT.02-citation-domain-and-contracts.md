# AI-09.4 — CIT.02: Citation Domain Model & Backend Contracts Implementation Report

## Executive Summary

As part of **AI-09.4 Source Citations and Document Preview**, milestone **CIT.02** establishes the backend domain model, relational persistence, transactional finalization, dynamic document-preview access resolution, and REST API contracts for source citations in Kynergy Intelligence.

Building upon the findings of the **CIT.01 Architecture Audit**, CIT.02 addresses the core architectural gap where retrieved chunk content was previously lost during citation mapping. It promotes source citations to first-class, immutable domain entities with dedicated relational persistence, strict tenant isolation, 1-based deterministic appearance ordering, evidentiary excerpt retention, point-in-time document title snapshotting, and dynamic document-availability status resolution.

All changes are non-destructive and preserve 100% backward compatibility with **FE.01 through FE.10** contracts.

---

## 1. Architectural Baseline & Provenance Tracing

During CIT.01, the audit identified that while AI-08 hybrid retrieval surfaces rich chunk evidence (`RAGEvidenceChunk`), the mapper `RAGSourceCitation.fromEvidenceChunk()` discarded `chunk.content` (the excerpt) and version provenance.

In CIT.02, end-to-end evidentiary provenance is preserved:

1. **RAG Retrieval Provenance Enriched**: `RAGSourceCitation.fromEvidenceChunk()` now maps `chunk.content` $\to$ `excerpt`, `chunk.documentVersionNumber` $\to$ `documentVersionNumber`, and `chunk.semanticRank ?? chunk.rrfRank` $\to$ `retrievalRank`.
2. **Canonical Attribution Sanitization**: `AiSourceAttributionService` validates, sanitizes, and deduplicates retrieved citations while preserving `citationId`, `documentVersionId`, `documentVersionNumber`, `excerpt`, and `retrievalRank`.
3. **Zero Fabricated Provenance**: No artificial retrieval metadata is generated. When historical messages or evidence chunks lack excerpts, the system explicitly indicates unavailable content rather than fabricating hallucinated provenance.

## 2. Domain Model & Invariants

Located in `packages/core/src/ai/domain/`:

### 2.1 Value Objects

- **`CitationId`** ([citation-id.vo.ts](file:///c:/Projects/kinergy-platform/packages/core/src/ai/domain/value-objects/citation-id.vo.ts)): Strongly typed, immutable UUID v4 identifier with factory methods `create()` and `generate()`.
- **`RAGSourceCitation`** ([rag-source-citation.vo.ts](file:///c:/Projects/kinergy-platform/packages/core/src/ai/domain/value-objects/rag-source-citation.vo.ts)): Enriched value object representing RAG pipeline citations with excerpts, document versions, and retrieval ranks.

### 2.2 Aggregate Entity

- **`AiConversationCitation`** ([ai-conversation-citation.entity.ts](file:///c:/Projects/kinergy-platform/packages/core/src/ai/domain/models/ai-conversation-citation.entity.ts)): First-class domain entity with strict domain invariants:
  - **Deterministic 1-Based Ordering**: `citationPosition` must be an integer $\ge 1$.
  - **Non-Empty Excerpt**: `excerpt` captures the exact snippet retrieved from the chunk; cannot be empty or whitespace-only.
  - **Point-in-Time Title Snapshot**: `documentTitleSnapshot` captures the document title at generation time, preserving historical evidentiary integrity even if the document is subsequently renamed or deleted.
  - **Relevance Score Bounds**: `relevanceScore`, when present, is strictly clamped to $[0.0, 1.0]$.
  - **Positive Page Number**: `pageNumber`, when present, must be an integer $\ge 1$.
  - **Immutability**: Freezes both the entity instance and its hierarchical `headingPath` array.

## 3. Relational Persistence & Database Migration

### 3.1 Prisma Schema

A dedicated relational model `AiConversationCitation` was added to `prisma/schema.prisma` ([schema.prisma](file:///c:/Projects/kinergy-platform/prisma/schema.prisma)):

```prisma
model AiConversationCitation {
  id                    String   @id @default(uuid()) @map("id")
  messageId             String   @map("message_id")
  turnId                String   @map("turn_id")
  conversationId        String   @map("conversation_id")
  tenantId              String   @map("tenant_id")
  documentId            String   @map("document_id")
  documentVersionId     String?  @map("document_version_id")
  chunkId               String?  @map("chunk_id")
  citationPosition      Int      @map("citation_position")
  documentTitleSnapshot String   @map("document_title_snapshot") @db.VarChar(255)
  excerpt               String   @map("excerpt") @db.Text
  pageNumber            Int?     @map("page_number")
  headingPath           String[] @default([]) @map("heading_path")
  retrievalRank         Int?     @map("retrieval_rank")
  relevanceScore        Float?   @map("relevance_score")
  sourceStrategy        String?  @map("source_strategy") @db.VarChar(64)
  metadata              Json?    @map("metadata")
  createdAt             DateTime @default(now()) @map("created_at")

  message  AiConversationMessage @relation("MessageToCitations", fields: [messageId, turnId, conversationId, tenantId], references: [id, turnId, conversationId, tenantId], onDelete: Cascade)
  document KnowledgeDocument     @relation("DocumentToCitations", fields: [documentId], references: [id], onDelete: Cascade)
  version  DocumentVersion?      @relation("VersionToCitations", fields: [documentVersionId], references: [id], onDelete: SetNull)
  chunk    KnowledgeChunk?       @relation("ChunkToCitations", fields: [chunkId], references: [id], onDelete: SetNull)

  @@unique([messageId, citationPosition], name: "uq_message_citation_position")
  @@unique([id, tenantId], name: "uq_citation_id_tenant")
  @@index([messageId], name: "idx_citation_message")
  @@index([conversationId], name: "idx_citation_conversation")
  @@index([tenantId, documentId], name: "idx_citation_tenant_document")
  @@index([chunkId], name: "idx_citation_chunk")
  @@map("ai_conversation_citations")
}
```

### 3.2 Non-Destructive Migration

Migration authored and deployed: `prisma/migrations/20261124190000_add_ai_conversation_citations/migration.sql`:

- **Unique Constraints**:
  - `uq_message_citation_position`: Guarantees deterministic order without collisions per message.
  - `uq_citation_id_tenant`: Guarantees strict multi-tenant boundary.
- **Composite Foreign Key**:
  - `fk_citations_message`: `(message_id, turn_id, conversation_id, tenant_id)` referencing `ai_conversation_messages` with `ON DELETE CASCADE`.
- **Soft-Delete Resilience**:
  - `fk_citations_version` and `fk_citations_chunk` use `ON DELETE SET NULL`, ensuring that chunk re-indexing or version archival never corrupts historical answer citations.
- **PostgreSQL Check Constraints**:
  - `chk_citation_position_positive`: `citation_position >= 1`.
  - `chk_citation_relevance_score_range`: `relevance_score >= 0.0 AND relevance_score <= 1.0`.
  - `chk_citation_page_number_positive`: `page_number IS NULL OR page_number >= 1`.
  - `chk_citation_excerpt_non_empty`: `length(trim(excerpt)) > 0`.

## 6. Dynamic Document Preview & Security Boundary

Neither document ID nor citation ID acts as an authorization token. All access is evaluated dynamically at query time:

### 6.1 Status Resolution Matrix

In `GetMessageCitationsUseCase` and `GetCitationDetailUseCase`:

- **`DOCUMENT_AVAILABLE`**: Document exists in tenant, is not deleted, and authenticated user has role clearance $\to$ full preview permitted (`canPreview: true`).
- **`DOCUMENT_SOFT_DELETED`**: Document has been archived or soft-deleted $\to$ evidentiary snapshot and excerpt displayed, preview disabled (`canPreview: false`).
- **`DOCUMENT_RESTRICTED`**: Document visibility classification exceeds caller's assigned roles $\to$ evidentiary snapshot and excerpt displayed, document viewer disabled (`canPreview: false`).
- **`EXCERPT_ONLY`**: Document record is unavailable or purged $\to$ evidentiary snapshot preserved, preview disabled (`canPreview: false`).

### 6.2 Hardened Controller Endpoints

1. `GET /api/v1/ai/knowledge/documents/:id/content` in `AiDocumentController`:
   - Hardened with `RetrievalSecurityPolicyService.resolveAllowedVisibilityScopes(user.roles)`.
   - Users lacking role clearance receive `403 Forbidden` (`You do not have the required role clearance to access or download this document.`).
2. `GET /api/v1/ai/knowledge/documents/:id/preview-metadata` in `AiDocumentController`:
   - Returns MIME type, file size, checksum, `canPreview`, `isAuthorized`, and `isDeleted` without exposing internal storage keys.

## 7. REST API Contracts

Mounted on `AiConversationController` under `/api/v1/ai/conversations`:

### 7.1 Message Citations Listing

`GET /api/v1/ai/conversations/:conversationId/messages/:messageId/citations`

- **Security**: `@UseGuards(AuthenticationGuard, AuthorizationGuard)`, `@TrustedAi()` parameter decorator.
- **Ordering**: Deterministic `citationPosition` ascending (1-based).
- **Response**: `MessageCitationsResponseDto` containing `citations: CitationDetailResponseDto[]`.

### 7.2 Single Citation Detail

`GET /api/v1/ai/conversations/:conversationId/messages/:messageId/citations/:citationId`

- **Security**: Verified tenant and message ownership.
- **Response**: `CitationDetailResponseDto` with full preview status and unavailable reason.
