# AI-09.10 — IT.07: Backend Integration and API Contract Tests

## Overview & Scope

The **IT.07** milestone verifies the real Kynergy Intelligence backend API, persistence, authorization, and asynchronous processing workflows independently of frontend mocks.

All tests execute against live PostgreSQL 16 container storage via Prisma ORM and validate exact HTTP request/response contracts, authorization rules (401, 403, 404, 200/201), relational invariants, concurrency controls, idempotency, signed preview tokens, and error sanitization.

## 1. Test Architecture & Coverage

### Core Integration Suite:

- **Test Suite**: [apps/api/src/ai/**tests**/ai-backend-api-contracts.integration.spec.ts](file:///c:/Projects/kinergy-platform/apps/api/src/ai/__tests__/ai-backend-api-contracts.integration.spec.ts)
- **Scenarios (20 tests)**:
  1. Rejects unauthenticated request with 401 Unauthorized.
  2. Rejects request with 401 on expired/invalid token.
  3. Rejects privileged audit inspection with 403 Forbidden for non-Owner role.
  4. Allows audit inspection for Owner and writes audit log to PostgreSQL (200 OK).
  5. Validates payload and rejects empty `userPrompt` with 400 Bad Request.
  6. Validates payload and rejects missing `clientTurnId` with 400 Bad Request.
  7. Creates conversation and returns authoritative DTO contract (201 Created).
  8. Lists conversations and returns paginated keyset contract (`items`, `nextCursor`, `hasMore`).
  9. Updates conversation title and returns updated DTO contract.
  10. Archives conversation and returns archival confirmation contract (soft-deleted in PostgreSQL).
  11. Rejects feedback targeting a USER message with 400 Bad Request.
  12. Submits, updates, retrieves, and revokes feedback on ASSISTANT message.
  13. Rejects turn regeneration with 409 Conflict when turn is still PENDING (`AI_TURN_ALREADY_IN_PROGRESS`).
  14. Regenerates turn when completed: increments attempt to 2, retains Attempt 1 intact, creates Attempt 2 message with `status: PENDING`.
  15. Retrieves message citations and streams document preview with secure headers.
  16. Handles idempotent turn replay without duplicate turn or message creation.
  17. Rejects concurrent turn reservation while an active turn is pending with 409 Conflict.
  18. Enforces multi-tenant IDOR protection: Tenant Beta cannot retrieve or mutate Tenant Alpha records.
  19. Returns standardized machine-readable error contracts with correlation headers (`x-correlation-id`, `x-request-id`).
  20. Redacts raw stack traces, SQL syntax, and internal infrastructure details from error responses.
