## 1. Executive Summary

This report delivers the comprehensive architecture and readiness audit for **AI-09.4: Source Citations and Document Preview**. In accordance with the execution constraints of CIT.01, this milestone is strictly an architectural investigation; zero production source code, database migrations, or endpoint contracts were modified.

The investigation encompassed the complete end-to-end slice of the Kynergy platform:

1. **Backend**: Conversation persistence (`AiConversation*`), RAG pipeline (`RAGOrchestratorService`, `SecureSemanticSearchService`, `RAGContextBuilderService`, `CitationValidatorService`), ingestion pipeline (`StructureAwareChunkerService`), and document management (`AiDocumentController`).
2. **Infrastructure**: PostgreSQL schema with `pgvector` (`knowledge_documents`, `document_versions`, `knowledge_chunks`, `document_embeddings`, `ai_conversation_messages`), and the object storage subsystem (`ObjectStoragePort`, `LocalStorageAdapter`, `S3StorageAdapter`).
3. **Frontend**: The Web Assistant module (`apps/web/src/modules/intelligence/assistant`), markdown parser (`MarkdownRenderer`), citation tray (`MessageCitations`), and design system primitives (`@kinergy-platform/ui`).

### Readiness Verdict: **READY WITH DEPENDENCIES**

The core infrastructure for citation attribution and file storage is mature, robust, and well-architected. However, real document preview and excerpt citation display cannot be achieved without addressing **four concrete architectural dependencies**:

1. **Excerpt Provenance Drop**: Chunks contain text excerpts in PostgreSQL (`knowledge_chunks.content`) and in memory during RAG execution (`RetrievedChunk.content`, `RAGEvidenceChunk.content`). However, `RAGSourceCitation.fromEvidenceChunk()` and `AiSourceAttributionService.validateAndSanitize()` intentionally drop `content` to optimize message JSON size. As a result, persisted messages in `ai_conversation_messages.sources` contain metadata (`documentId`, `documentTitle`, `chunkId`, `pageNumber`, `headingPath`, `relevanceScore`), but **not the actual textual excerpt**.
2. **Lack of Chunk Preview Endpoint**: There is currently no backend endpoint to retrieve a single chunk's text and provenance on-demand (e.g., `GET /api/v1/ai/knowledge/chunks/:chunkId`).
3. **Authorization Asymmetry on Document Downloads**: In RAG retrieval, `RetrievalSecurityPolicyService` enforces strict role-based visibility scopes (`ALL_STAFF`, `CLINICAL_STAFF`, `MANAGEMENT_ONLY`) in SQL. In contrast, the binary document download endpoint (`GET /api/v1/ai/knowledge/documents/:id/content` in `AiDocumentController`) checks tenant isolation but **does not enforce role-based visibility scopes**.
4. **Frontend Interactive Citations & Viewer Gap**: The frontend chat interface renders static badge pills (`[1] Title p.X`) with external browser links (`target="_blank"`), but has no inline citation marker parsing (`[1]`), no source detail drawer/sheet, and no in-app preview container (PDF or text).

## 3. RAG Provenance Trace

A step-by-step trace of a live retrieval operation demonstrates how source metadata flows through the system and where critical fields are transformed or discarded:

### Step 1: Retrieval Initiation

- **Service**: `SecureSemanticSearchService.execute()`
- **Action**: Executes hybrid retrieval (vector cosine distance on `document_embeddings` + full-text search on `knowledge_chunks.tsv`). Filters by `tenant_id`, `visibility_scope IN (...)`, and `deleted_at IS NULL`.
- **Output**: An array of `RetrievedChunk` domain objects.
- **Data Preserved**:
  - `RetrievedChunk.chunkId` = UUID
  - `RetrievedChunk.documentId` = UUID
  - `RetrievedChunk.documentVersionId` = UUID
  - `RetrievedChunk.content` = Full text of the chunk (500–1000 chars)
  - `RetrievedChunk.provenance.pageNumber` = Page integer (or null)
  - `RetrievedChunk.provenance.headingPath` = Array of section titles (`['1. Evaluación', '1.2 Marcha']`)
  - `RetrievedChunk.similarity` = Cosine score (0.0 to 1.0)

### Step 2: Context Construction

- **Service**: `RAGContextBuilderService.buildContext()`
- **Action**: Deduplicates chunks, formats XML prompt blocks (`<chunk id="chk-...">...</chunk>`), and budgets tokens within context window limits.
- **Output**: `RAGConstructedContext` containing `includedChunks: RAGEvidenceChunk[]`.
- **Data Preserved**:
  - `RAGEvidenceChunk.content` is fully preserved.
  - Multi-arm ranking metrics (`semanticRank`, `keywordRank`, `rrfRank`) are present.

### Step 3: LLM Answer Synthesis & Citation Parsing

- **Service**: `GroundedGenerationService` & `CitationValidatorService`
- **Action**: LLM returns synthesized text with inline bracket citations (e.g. `"...análisis cinemático [chk-1]"`). `CitationValidatorService` matches `[chk-1]` against `includedChunks`.
- **Transformation / Provenance Drop**:
  - `RAGSourceCitation.fromEvidenceChunk(evidence)` is called.
  - **The text `content` (excerpt) is dropped**. `RAGSourceCitation` only captures:
    `{ documentId, documentTitle, chunkId, pageNumber, headingPath, relevanceScore, sourceStrategy }`.

### Step 4: Persistent Turn Finalization

- **Service**: `ExecuteConversationTurnUseCase` & `AiSourceAttributionService`
- **Action**: `AiSourceAttributionService.validateAndSanitize()` runs security checks (strips filesystem paths, database URIs, verifies bounds `[0.0, 1.0]`) and calls `serializeForPersistence()`.
- **Persistence Target**: `ai_conversation_messages.sources` (JSONB column).
- **Data Persisted**:
  ```json
  [
    {
      "documentId": "48b6c0e8-0b53-4889-bcf7-6bcfc70fdb55",
      "documentTitle": "Guía Clínica de Biomecánica y Marcha 2026",
      "chunkId": "1b9a9f24-2c38-4fbb-91b7-a0e5b95a8641",
      "pageNumber": 14,
      "headingPath": ["Protocolos de Evaluación", "Análisis Cinemático"],
      "relevanceScore": 0.8842,
      "sourceStrategy": "HYBRID"
    }
  ]
  ```
- **Provenance Deficit**: The excerpt string (`content`) and `documentVersionNumber` are not in the stored JSON.

### Step 5: Frontend History Hydration & Rendering

- **Component**: `apps/web/.../components/assistant-message.tsx`
- **Consumer**: `MessageCitations` receives `sources: RAGSourceCitationDto[]`.
- **Render State**: Renders badge items displaying `[1] Guía Clínica... p.14` with a hyperlink pointing directly to `/api/v1/ai/knowledge/documents/:documentId/content`.
- **Interaction Limitation**: When a clinician clicks the link, the browser opens the entire raw document in a new tab; there is no drawer showing the specific chunk excerpt that justified the clinical answer.

## 5. Message Persistence Audit

### 5.1 Persistence Timing & Durability

- **User Message**: Persisted immediately upon turn reservation in `AiConversationController.reserveTurn()` or synchronously in `assistantStorageService`.
- **Assistant Message**: In PENDING status during active generation. Finalized in a single PostgreSQL transaction inside `ExecuteConversationTurnUseCase` upon successful completion.
- **Historical Durability**: Because `ai_conversation_messages.sources` is a persistent JSONB column, historical assistant messages **reliably survive browser refresh** and rehydrate identically in `conversation-retrieval.spec.tsx` and `conversation-e2e-scenarios.spec.tsx`.

### 5.2 Failure & Interruption Handling

- **Failed Turn**: If inference throws an unrecoverable provider error (e.g., 500 LLM failure), `AiSourceAttributionService` guarantees that `sources` is persisted as `[]` or `null`. An error message never presents unverified citations.
- **Cancelled / Interrupted Turn**: If the client aborts generation mid-stream or the worker experiences a shutdown, `status = CANCELLED` / `INTERRUPTED` is committed with `sources = null`.

## 6. Document Management & Storage Audit

### 6.1 Storage Abstraction (`ObjectStoragePort`)

The application defines a strict storage port abstraction located at [object-storage.port.ts](file:///c:/Projects/kinergy-platform/apps/api/src/platform/storage/ports/object-storage.port.ts):

- `upload(tenantId, domainFolder, filename, buffer, mimeType): Promise<StoredObjectMetadata>`
- `download(tenantId, key): Promise<{ data: Buffer; metadata: StoredObjectMetadata }>`
- `createPresignedDownloadUrl(tenantId, key, expiresInSeconds): Promise<PresignedDownloadResult>`
- `createPresignedUploadUrl(...)`

### 6.2 Backing Adapters

- **Local Storage ([local-storage.adapter.ts](file:///c:/Projects/kinergy-platform/apps/api/src/platform/storage/adapters/local-storage.adapter.ts))**: Active in local development (`STORAGE_DRIVER=local`). Resolves files to `storage/` on disk, enforces tenant root isolation (`tenants/{tenantId}/knowledge/...`), computes MD5 checksums, and manages `.meta.json` sidecars.
- **S3 Storage ([s3-storage.adapter.ts](file:///c:/Projects/kinergy-platform/apps/api/src/platform/storage/adapters/s3-storage.adapter.ts))**: Active in cloud deployments (`STORAGE_DRIVER=s3`). Interfaces with AWS S3 or MinIO.

### 6.3 Document Versioning & Immutability

- Documents have one logical identity (`KnowledgeDocument`) and multiple immutable versions (`DocumentVersion`).
- Files are stored with content-addressed keys: `tenants/{tenantId}/knowledge/{documentId}/{versionId}-{filename}`.
- Deleting a document executes a **soft-delete** (`deletedAt = now()`), retaining the underlying binary file in storage to preserve medical audit trails and citation integrity for older conversation turns.

## 7. Authorization Audit

A security discrepancy exists between RAG retrieval and binary document download:

### 7.1 RAG Retrieval Authorization (Strict)

In [retrieval-security-policy.service.ts](file:///c:/Projects/kinergy-platform/apps/api/src/ai/services/retrieval/retrieval-security-policy.service.ts):

- User roles from the verified JWT are mapped to visibility scopes:
  - `ADMIN`, `DIRECTOR` $\to$ `ALL_STAFF`, `CLINICAL_STAFF`, `MANAGEMENT_ONLY`
  - `KINESIOLOGIST`, `PHYSIOTHERAPIST` $\to$ `ALL_STAFF`, `CLINICAL_STAFF`
  - `RECEPTIONIST`, `STAFF` $\to$ `ALL_STAFF`
- Chunks from documents with unauthorized scopes are filtered out directly in SQL before similarity ranking.

### 7.2 Document Content Download Authorization (Permissive)

In [ai-document.controller.ts](file:///c:/Projects/kinergy-platform/apps/api/src/ai/controllers/ai-document.controller.ts) (`GET :id/content`):

- `AuthenticationGuard` checks JWT validity.
- The controller verifies that `tenantId` in the JWT matches `tenantId` of the document.
- **Critical Gap**: The endpoint **does not inspect user roles against `document.visibilityScope`**. Any authenticated user who obtains a document UUID can download the complete original document, bypassing the clinical visibility restrictions enforced during RAG retrieval.

## 8. Frontend Capability Audit

### 8.1 Existing Reusable Assets

- **Design System**: Radix UI Dialog primitive (`@radix-ui/react-dialog`) in `@kinergy-platform/ui` provides accessible modal overlays.
- **Styling**: Tailwind CSS with standard design tokens (`bg-card`, `border-border/60`, `text-primary`).
- **Icons**: `lucide-react` includes `ExternalLink`, `FileText`, `Layers`, `Search`, `Eye`, `BookOpen`.
- **Query Caching**: TanStack Query v5 is configured with query invalidation patterns and keyset factories.

### 8.2 Gaps in Chat UI

- **No Inline Citation Markers**: `MarkdownRenderer` only parses `[link text](url)`. Standalone references like `[1]` or `[chk-1]` render as inert plain text instead of clickable interactive badges.
- **No Source Detail Drawer**: Clicking a source citation does not open a slide-over drawer displaying excerpt text, heading hierarchy, or match confidence.
- **No In-App PDF / Document Previewer**: No embedded `<iframe />` or `<object />` wrapper with JWT bearer authorization headers exists to view the document within the workspace.
- **No Unavailable Source Fallback**: If a document has been deleted or archived, clicking the link results in a raw browser 404 page.

## 10. Architectural Gaps & Implementation Recommendations

### 10.1 Identified Architectural Gaps

1. **Excerpt Retrieval Architecture (Gap G-1)**:
   - _Problem_: `ai_conversation_messages.sources` lacks the text excerpt. Loading excerpts directly into every message would bloat conversation history payloads.
   - _Solution_: Implement a dedicated on-demand endpoint `GET /api/v1/ai/knowledge/documents/:documentId/chunks/:chunkId` (or `GET /api/v1/ai/knowledge/chunks/:chunkId`) that loads the chunk content directly from `knowledge_chunks` with tenant and visibility authorization. Alternatively, store a sanitized 200-character excerpt preview in `CanonicalSourceCitation`.
2. **Download Endpoint Authorization Hardening (Gap G-2)**:
   - _Problem_: `AiDocumentController.downloadContent` allows cross-role document leakage within the same tenant.
   - _Solution_: Inject `RetrievalSecurityPolicyService` into `AiDocumentController` and verify `user.roles` against `document.visibilityScope` before streaming file bytes.
3. **Frontend Citation & Drawer Infrastructure (Gap G-3)**:
   - _Problem_: Chat UI lacks interactive citation exploration.
   - _Solution_:
     - Update `MarkdownRenderer` to parse citation tokens `\[(\d+)\]` into interactive `<CitationBadge index={n} onClick={...} />`.
     - Build a slide-over `SourceDrawer` component showing Document Title, Page Number, Heading Path, Relevance Score, and the authoritative Excerpt text.
4. **Document Preview Integration (Gap G-4)**:
   - _Problem_: Clicking "View Document" currently initiates a raw browser navigation.
   - _Solution_: Provide an in-app preview modal leveraging the browser's native PDF viewing engine via an authenticated blob URL or tokenized iframe URL, with a fallback download action for DOCX/TXT files.
