## 1. Executive Summary & Architectural Scope

Following the successful database foundation established in **AI-09.3-BE.02.01**, sub-phase **AI-09.3-BE.02.02** implements the application-independent domain model, outbound repository ports, and Prisma persistence adapters for persistent AI conversations.

### 1.1 Strict Boundary Enforcement

1. **Clean Architecture & Packaging Invariants:**
   - **Domain Layer (`packages/core/src/ai/domain/`):** Pure TypeScript. Zero dependencies on Prisma, NestJS, HTTP frameworks, or backend runtimes. Fully browser-safe and portable.
   - **Outbound Ports (`packages/core/src/ai/ports/outbound/`):** Pure TypeScript interfaces defining storage contracts and query signatures without leaking ORM details.
   - **Persistence Infrastructure (`packages/core/src/ai/infrastructure/persistence/prisma/`):** Server-only adapters, mappers, and repositories that implement the outbound ports using Prisma Client.
   - **Packaging Exports:**
     - Browser-safe root entry point (`@kinergy-platform/core`, via `packages/core/src/index.ts`) exports domain entities, value objects, enums, exceptions, and ports.
     - Server-only entry point (`@kinergy-platform/core/server`, via `packages/core/src/server.ts`) exports Prisma mappers and repositories. It is architecturally forbidden from being imported by browser bundles (`apps/web`).
2. **Explicitly Excluded Scope (Reserved for BE.02.03 and beyond):**
   - Atomic reservation transaction services and generation coordination (BE.02.03).
   - REST endpoints and SSE streaming controllers (BE.02.04).
   - Background lease-recovery and migration drain cron jobs (BE.02.05).
   - Web frontend UI integration (FE.01).

## 2. Domain Models & Value Objects

### 2.1 Domain Enums

Located in `packages/core/src/ai/domain/enums/`:

- `ConversationRole`: `'USER' | 'ASSISTANT' | 'SYSTEM'` (with `isValidConversationRole` type guard).
- `GenerationStatus`: `'PENDING' | 'STREAMING' | 'SUCCESS' | 'FAILED' | 'CANCELLED' | 'INTERRUPTED'` (with `isValidGenerationStatus` type guard).
- `TurnStatus`: `'PENDING' | 'STREAMING' | 'COMPLETED' | 'FAILED' | 'CANCELLED' | 'INTERRUPTED'` (with `isValidTurnStatus` type guard).

### 2.2 Value Objects

Located in `packages/core/src/ai/domain/value-objects/`:

- **`ConversationId`:** Immutable aggregate root identifier with isomorphic UUID generation and string comparison equality.
- **`TurnId`:** Immutable turn entity identifier.
- **`MessageId`:** Immutable message entity identifier.
- **`ClientTurnId`:** Client-supplied turn identifier for idempotency and correlation; enforces non-empty string and a maximum length of 64 characters (matching database schema constraints).
- **`ConversationTitle`:** Conversation display title; validates length (1..255 characters), defaults to `"New Conversation"`, and provides `deriveFromPrompt(prompt, maxLength)` to safely distill user queries into concise titles.
- **`MessageHistoryCursor`:** Keyset pagination cursor encoding `{ sequenceNumber: number, messageId: string }` into URL-safe Base64URL. Enforces `sequenceNumber >= 1` and non-empty `messageId`.

### 2.3 Domain Entities

Located in `packages/core/src/ai/domain/models/`:

#### 1. `AiConversation` (Aggregate Root)

- **State:** `id`, `tenantId`, `userId`, `title`, `idempotencyKey`, `turnCounter`, `messageCounter`, `lastActivityAt`, `createdAt`, `updatedAt`, `deletedAt`.
- **Invariants:** Strictly partitioned by `tenantId` and owned by `userId`. Non-negative integer counters.
- **Lifecycle Methods:** `updateTitle()`, `archive()`, `unarchive()`, `recordActivity()`, `incrementTurnCounter()`, `incrementMessageCounter()`.

#### 2. `AiConversationTurn` (Turn Entity)

- **State:** `id`, `conversationId`, `tenantId`, `turnIndex`, `status`, `clientTurnId`, `idempotencyKey`, `idempotencyPayloadHash`, `activeAttemptId`, `activeAttemptNumber`, `createdAt`, `completedAt`, `updatedAt`.
- **Invariants:** `turnIndex >= 1`, `activeAttemptNumber >= 1`.
- **State Transitions:** `markStreaming()`, `markCompleted()`, `markFailed()`, `markCancelled()`, `markInterrupted()`, `setActiveAttempt()`.

#### 3. `AiConversationMessage` (Message Entity)

- **State:** `id`, `turnId`, `conversationId`, `tenantId`, `role`, `sequenceNumber`, `attemptNumber`, `isCanonical`, `status`, `content`, `sources`, `metadata`, `errorCode`, `errorMessage`, `clientMessageId`, `leaseToken`, `leaseOwnerInstanceId`, `leaseExpiresAt`, `createdAt`, `completedAt`, `updatedAt`.
- **Invariants:**
  - `sequenceNumber >= 1`, `attemptNumber >= 1`.
  - For `role === 'USER'`: `status = SUCCESS`, `attemptNumber = 1`, and `isCanonical = false` (enforced to align with the PostgreSQL check constraint `chk_canonical_requires_success` where `is_canonical` applies strictly to `ASSISTANT` messages).
  - For `role === 'ASSISTANT'`: at most one canonical message per turn is permitted.
- **Lifecycle Methods:** `appendContentChunk()`, `complete()`, `fail()`, `cancel()`, `interrupt()`, `acquireLease()`, `releaseLease()`.

#### 4. `AiConversationAuditLog` (Audit Entity)

- **State:** `id`, `tenantId`, `conversationId`, `conversationTitleSnapshot`, `conversationOwnerUserId`, `inspectorUserId`, `inspectorRole`, `action`, `reason`, `ipAddress`, `userAgent`, `createdAt`.
- **Invariants:** Immutable (`Object.freeze`). Mandatory tenant, conversation owner, inspector, and justification reason fields.

## 3. Domain Exceptions & Invariants

Located in `packages/core/src/ai/domain/exceptions/conversation.exceptions.ts`:

- `ConversationNotFoundException`: Thrown when a conversation cannot be found within the tenant boundary.
- `UnauthorizedConversationAccessException`: Thrown upon tenant crossing attempts or cross-user unauthorized access.
- `InvalidConversationTurnException`: Thrown on invalid turn, role, or formatting invariants.
- `TurnNotFoundException`: Thrown when an expected turn is missing.
- `MessageNotFoundException`: Thrown when an expected message is missing.
- `InvalidCursorException`: Thrown when a pagination cursor is malformed, corrupted, or contains invalid sequence numbers.
- `InvalidMessageInvariantException`: Thrown when message invariants (e.g., USER message status/canonical flags or non-positive sequence numbers) are violated.

### 5.1 Relational & Keyset Pagination Implementation Highlights

- **Atomic Upserting:** All entity saves utilize Prisma's composite unique keys (`uq_conversation_id_tenant`, `uq_turn_id_conv_tenant`, `uq_msg_id_turn_conv_tenant`), ensuring safe transactional updates and idempotency.
- **Tenant Isolation:** Every repository method unconditionally scopes queries by `tenantId`.
- **Keyset Cursor Pagination (`listCanonicalHistory`):**
  - Filters strictly for canonical dialogue: `OR: [ { role: 'USER' }, { isCanonical: true } ]`.
  - Applies keyset seek predicate: `sequenceNumber > cursor.sequenceNumber`.
  - Orders by `[{ sequenceNumber: 'asc' }, { id: 'asc' }]`.
  - Fetches `limit + 1` rows to determine pagination termination, returning `nextCursor` when further records exist.
