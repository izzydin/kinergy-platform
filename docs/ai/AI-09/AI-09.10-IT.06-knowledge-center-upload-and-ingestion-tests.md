# AI-09.10 — IT.06: Knowledge Center, Upload, and Ingestion Tests

## Overview & Scope

The **IT.06** milestone establishes comprehensive frontend and backend integration tests for the Kynergy Intelligence Knowledge Center. It validates the full document lifecycle from listing, searching, client-side validation, multipart upload, background ingestion state progression, failure handling, versioning, and authorized preview.

---

## 1. Test Architecture & Coverage

### Backend Integration:

- **Test Suite**: [apps/api/src/ai/controllers/**tests**/ai-knowledge-ingestion-lifecycle.integration.spec.ts](file:///c:/Projects/kinergy-platform/apps/api/src/ai/controllers/__tests__/ai-knowledge-ingestion-lifecycle.integration.spec.ts)
- **Scenarios (16 tests)**:
  - Document listing with scope and tenant isolation.
  - Multipart upload validation (file size bounds, allowed MIME types).
  - Seven-stage asynchronous ingestion FSM transitions: `UPLOADED` -> `VALIDATING` -> `PROCESSING` -> `INDEXING` -> `READY` / `FAILED`.
  - Ingestion job failure recovery with retry limits and transient backoff.
  - Multi-tenant IDOR protection: cross-tenant access returns 404/403.
  - Document soft-deletion and version pinning.

### Frontend Integration:

- **Test Suite**: [apps/web/src/modules/intelligence/knowledge/**tests**/knowledge-center-full-lifecycle.integration.spec.tsx](file:///c:/Projects/kinergy-platform/apps/web/src/modules/intelligence/knowledge/__tests__/knowledge-center-full-lifecycle.integration.spec.tsx)

- **Scenarios**:
  - Document table keyset sorting, search filtering, and pagination.
  - File upload modal validation with progress feedback.
  - Ingestion lifecycle timeline polling and live status stepper.
  - Empty, loading, and error states distinction.
