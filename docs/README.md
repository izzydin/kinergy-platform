# Kinergy Platform Documentation Directory

Welcome to the central documentation portal for the **Kinergy Platform**.

---

## Documentation Categories

- **[Architecture Guide (`docs/architecture/`)](./architecture/README.md)**:
  System topology, Clean Architecture layers, Domain-Driven Design strategy, Bounded Contexts, Platform Layer services, Dependency Inversion, Repository pattern, and CQRS decisions.
- **[Architectural Decision Records (`docs/adr/`)](./adr/README.md)**:
  Formal ADR records (ADR 0001 - 0015) documenting monorepo framework choices, tooling, Docker infrastructure, NestJS, React + Vite, Prisma, and shared domain kernel design.
- **[API Documentation (`docs/api/`)](./api/README.md)**:
  OpenAPI Swagger endpoint specifications, REST API schemas, and request/response contracts.
- **[Business Documentation (`docs/business/`)](./business/README.md)**:
  Business domain requirements, functional specifications, and ubiquitous language glossary.
- **[Development Setup Guide (`docs/development/`)](./development/README.md)**:
  Local setup instructions, pnpm workflow, Docker Compose environment, and testing guidelines.
