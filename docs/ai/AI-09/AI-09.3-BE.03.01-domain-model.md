## 2. Implemented Domain Entities

All domain entities encapsulate their state, control mutations via domain methods, protect business invariants, and track audit timestamps without exposing raw persistence primitives.

### 2.1 `AiConversation`

- **Source File:** [ai-conversation.entity.ts](file:///c:/Projects/kinergy-platform/packages/core/src/ai/domain/entities/ai-conversation.entity.ts)
- **Role:** Aggregate root representing an isolated multi-turn conversational session bound to a tenant and user.
- **Key Methods & Invariants:**
  - `create(...)`: Factory for brand new conversations with default counters (`totalTurns = 0`, `totalMessages = 0`) and `ACTIVE` state.
  - `createFromInitialPrompt(...)`: Factory creating an active conversation while deriving an initial title from the first user prompt (truncated cleanly up to 40 characters).
  - `updateTitle(newTitle: ConversationTitle)`: Updates title and updates `updatedAt` timestamp.
  - `archive()` & `unarchive()`: Controlled state transitions for conversational lifecycle.
  - `incrementTurnCount()` & `incrementMessageCount()`: Monotonic counter progression.
  - `reconstitute(...)`: Reconstructs persisted state without re-running creation side-effects.

### 2.2 `AiConversationTurn`

- **Source File:** [ai-conversation-turn.entity.ts](file:///c:/Projects/kinergy-platform/packages/core/src/ai/domain/entities/ai-conversation-turn.entity.ts)
- **Role:** Entity representing a single prompt-response turn in a conversation.
- **Key Methods & Invariants:**
  - `create(...)`: Factory initializing turn with `PENDING` status, `activeAttemptNumber = 1`, and `turnIndex >= 1`.
  - `isTerminal()`: Computes whether the turn has reached an immutable state (`COMPLETED`, `FAILED`, `CANCELLED`, `INTERRUPTED`).
  - `markStreaming()`: Enforces that turns in a terminal state cannot transition back to streaming (throws `InvalidLifecycleTransitionException`).
  - `associateActiveAttempt(attempt: AiConversationMessage)`: Validates that the active generation attempt strictly belongs to this turn, conversation, and tenant, and has role `ASSISTANT`. Throws `InvalidMessageOwnershipException` if boundary check fails.
  - `complete(...)`, `fail(...)`, `cancel(...)`, `interrupt(...)`: Terminal transitions updating status and recording completion timestamps.

### 2.3 `AiConversationMessage`

- **Source File:** [ai-conversation-message.entity.ts](file:///c:/Projects/kinergy-platform/packages/core/src/ai/domain/entities/ai-conversation-message.entity.ts)
- **Role:** Entity representing a message or assistant generation attempt within a turn.
- **Key Methods & Invariants:**
  - `createUserMessage(...)`: Factory enforcing user message invariants (`role = USER`, `status = SUCCESS`, `isCanonical = false`, `attemptNumber = 1`).
  - `createAssistantAttempt(...)`: Factory initializing an assistant generation attempt with `PENDING` status and optional lease parameters.
  - `isTerminal()`: Computes whether the message has reached terminal status (`SUCCESS`, `FAILED`, `CANCELLED`, `INTERRUPTED`).
  - `appendContentChunk(chunk: string)`: Rejects appending content if message is terminal (throws `InvalidLifecycleTransitionException`).
  - `acquireLease(...)`: Rejects leasing if message is in a terminal state.
  - `setCanonical(canonical: boolean)`: Enforces that only `ASSISTANT` messages with `SUCCESS` status can be designated canonical (`chk_canonical_requires_success` parity). Throws `InvalidCanonicalDesignationException` on violation.
  - `complete(...)`, `fail(...)`, `cancel(...)`, `interrupt(...)`: Automatically clears active lease tokens, expiration dates, and lease owner instance IDs upon reaching terminal states (`chk_terminal_attempt_no_active_lease` parity).

### 2.4 `AiConversationAuditLog`

- **Source File:** [ai-conversation-audit-log.entity.ts](file:///c:/Projects/kinergy-platform/packages/core/src/ai/domain/entities/ai-conversation-audit-log.entity.ts)

## 4. Domain Exceptions

Located in [packages/core/src/ai/domain/exceptions/conversation.exceptions.ts](file:///c:/Projects/kinergy-platform/packages/core/src/ai/domain/exceptions/conversation.exceptions.ts):

1. **`ConversationException`**: Base class extending standard `Error` with domain code categorization.
2. **`InvalidEntityIdentityException`**: Thrown when UUIDs, client turn IDs, or tenant IDs fail validation.
3. **`InvalidLifecycleTransitionException`**: Thrown when transitioning from a terminal turn/message state back to streaming/pending, or appending content chunks to finalized attempts.
4. **`InvalidMessageOwnershipException`**: Thrown when associating an active attempt whose `turnId`, `conversationId`, `tenantId`, or `role` does not match the parent turn.
5. **`InvalidCanonicalDesignationException`**: Thrown when attempting to designate `is_canonical = true` on a `USER` message or an assistant attempt whose status is not `SUCCESS`.

## 5. Domain Invariants vs Database Enforcement Parity

| Domain Rule                         | Domain Layer Enforcement                                                                                       | Database Layer Enforcement                                                               |
| :---------------------------------- | :------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------- |
| **Canonical Assistant Rule**        | `InvalidCanonicalDesignationException` thrown if `role !== ASSISTANT` or `status !== SUCCESS`                  | `chk_canonical_requires_success` check constraint                                        |
| **Single Canonical Assistant**      | Ensured via single canonical setter on turn aggregate                                                          | Partial unique index `uq_turn_single_canonical_assistant`                                |
| **Single User Message per Turn**    | Factory rules and turn aggregate                                                                               | Partial unique index `uq_turn_single_user_message`                                       |
| **Terminal Lease Clearance**        | `complete()`, `fail()`, `cancel()`, `interrupt()` clear `leaseToken`, `leaseExpiresAt`, `leaseOwnerInstanceId` | `chk_terminal_attempt_no_active_lease` check constraint                                  |
| **Turn Active Attempt Ownership**   | `associateActiveAttempt()` checks turn, conversation, tenant, and assistant role                               | Deferrable constraint trigger `trg_validate_turn_active_attempt`                         |
| **Message Relational Immutability** | Getters only; no setter mutations for `role`, `turnId`, `conversationId`, `tenantId`                           | `trg_protect_message_immutability` trigger                                               |
| **Positive Indices**                | Constructor validation for `turnIndex >= 1`, `sequenceNumber >= 1`, `attemptNumber >= 1`                       | `chk_turn_index_positive`, `chk_sequence_number_positive`, `chk_attempt_number_positive` |
