# AI-10.0 — SEC.05: Prompt Construction and Prompt-Injection Threat Assessment

**Status:** COMPLETED / VERIFIED  
**Date:** November 2026  
**Auditor:** Senior LLM Application Security Engineer & AI Safety Architect  
**Scope:** Prompt Construction Pipeline, System Prompt Templates, Trust Level Segregation, Direct & Indirect Prompt Injection Defenses, Tool Boundaries, and Output Rendering (SEC.05)  
**Classification:** Internal Security Working Document

## Executive Summary

This assessment evaluated the prompt construction pipeline, system prompt templates, context encapsulation mechanics, LLM inference boundaries, and downstream output rendering in **Kynergy Intelligence**.

The audit verified strong architectural protections against direct and indirect prompt injection:

1. **Server-Side Authorization Decoupling:** Authorization is enforced 100% outside the LLM. SQL pre-filtering and RBAC clearance prevent unauthorized chunks from ever reaching the prompt assembly layer. The LLM is never relied upon as an access control enforcement mechanism.
2. **Untrusted XML Context Delimitation:** [RAGContextBuilderService](file:///c:/Projects/kinergy-platform/apps/api/src/ai/services/rag/rag-context-builder.service.ts) encapsulates retrieved chunks inside structured XML boundaries (`<retrieved_evidence><evidence_chunk>`). All closing delimiter tags (`</evidence_chunk>`, `</retrieved_evidence>`, `<system>`, `<instruction>`) in untrusted document text are escaped to prevent prompt breakouts.
3. **Whole-Chunk Token Budgeting:** When token budgets are exceeded, lower-ranked chunks are dropped completely. Text is never substring-truncated, eliminating the dangerous inversion of clinical contraindications (e.g., truncating _"no realizar carga"_ into _"realizar carga"_).
4. **Deterministic Abstention & Post-Generation Verification:** [GroundedGenerationService](file:///c:/Projects/kinergy-platform/apps/api/src/ai/services/rag/grounded-generation.service.ts) and [citation-validator.service.ts](file:///c:/Projects/kinergy-platform/apps/api/src/ai/services/rag/citation-validator.service.ts) cross-check model-cited chunk IDs against authorized chunks in the prompt, stripping hallucinated citations and flipping `grounded: false` on unverified claims.
5. **No Tool Execution Surface:** Kynergy Intelligence does not enable tool use or function calling in Ollama. The model functions exclusively as a read-only reasoning synthesizer, eliminating remote code execution or unauthorized backend action risks.
6. **Zero Image Exfiltration Surface:** [markdown-renderer.tsx](file:///c:/Projects/kinergy-platform/apps/web/src/modules/intelligence/assistant/components/markdown-renderer.tsx) does not render Markdown `<img>` tags, eliminating automatic data exfiltration via image GET requests.

### Identified Security Findings

- **SEC05-F01 (Low — CVSS 3.3): Lack of Automated Post-Generation System Prompt Scrubber.** While Rule 9 instructs the model not to reveal system instructions, there is no deterministic regex/token filter scanning the output `answer` for system prompt leakage.
- **SEC05-F02 (Medium — CVSS 4.3): Unrestricted External Hyperlink Rendering in Web Client.** [markdown-renderer.tsx](file:///c:/Projects/kinergy-platform/apps/web/src/modules/intelligence/assistant/components/markdown-renderer.tsx) permits any `http://` or `https://` link generated by the model or extracted from malicious documents, rendering clickable links without domain allowlisting or an interstitial warning modal.
- **SEC05-F03 (Low — CVSS 2.6): Unescaped Markdown Section Delimiters in Retrieved Evidence.** Document chunks containing `### USER INQUIRY:` or `### CONVERSATION HISTORY:` are not indented or escaped, creating potential structural confusion with the outer prompt framing.

## 1. Prompt Construction Flow

```
[ User Request: query, conversationId ]
       │
       ▼
1. Conversation History Resolution
   - ConversationHistoryManagerService:
     - Enforces conversation.userId === actorId
     - Strips client-supplied 'system' role messages
     - Escapes injection tags (<system>, <instruction>, <retrieved_evidence>)
     - Bounds history to maxTurns (10) and maxTokens (500)
       │
       ▼
2. Authorized Retrieval Execution
   - SecureSemanticSearchService:
     - Pre-filters by tenantId & allowedVisibilityScopes in PostgreSQL
     - Retrieves only authorized chunks (e.g. top-5 via RRF)
       │
       ▼
3. Context XML Encapsulation
   - RAGContextBuilderService:
     - Wraps chunks in <evidence_chunk id="..." document_id="..." title="..." version="...">
     - Escapes closing XML tags inside chunk text (&lt;/evidence_chunk&gt;)
     - Applies complete chunk dropping when budget is exceeded
       │
       ▼
4. System Prompt Assembly
   - buildRAGSystemPrompt(language):
     - Injects 14 Authoritative Operating Rules
     - Enforces strict JSON output schema: { answer, grounded, citedChunkIds, abstentionReason }
       │
       ▼
5. User Prompt Assembly
   - buildRAGUserPrompt:
     - Concatenates:
       ### CONVERSATION HISTORY: ...
       ### RETRIEVED EVIDENCE: <retrieved_evidence> ... </retrieved_evidence>
       ### USER INQUIRY: ...
       Synthesize a grounded answer based strictly on the retrieved evidence above...
       │
       ▼
6. Model Inference (Ollama / Qwen3:4b)
   - OllamaLLMAdapter:
     - POST /api/generate
     - format: "json", temperature: 0.2, num_predict: 512, num_ctx: 4096, think: false
       │
       ▼
7. Post-Generation Verification
   - GroundedGenerationService & CitationValidatorService:
     - Decodes JSON payload
     - Cross-checks citedChunkIds against includedChunks
     - Strips unverified/hallucinated chunk IDs
     - Overrides grounded = false if zero verified citations or explicit abstention phrasing
       │
       ▼
8. Persistence & Client Response
   - Response persisted to ai_conversation_turns
   - Rendered in frontend via custom React MarkdownRenderer
```

## 6. Output and Downstream Processing Risks

[markdown-renderer.tsx](file:///c:/Projects/kinergy-platform/apps/web/src/modules/intelligence/assistant/components/markdown-renderer.tsx) was audited for DOM injection vulnerabilities:

1. **No `dangerouslySetInnerHTML`:** The renderer parses Markdown into native React DOM elements (`<strong>`, `<em>`, `<code>`, `<a>`, `<table>`). Raw HTML strings are never injected into the DOM.
2. **Strict Protocol Validation (`isSafeUrl`):**
   ```ts
   function isSafeUrl(url: string): boolean {
     const trimmed = url.trim().toLowerCase();
     if (
       trimmed.startsWith('javascript:') ||
       trimmed.startsWith('data:') ||
       trimmed.startsWith('vbscript:')
     ) {
       return false;
     }
     return (
       trimmed.startsWith('http://') ||
       trimmed.startsWith('https://') ||
       trimmed.startsWith('mailto:') ||
       trimmed.startsWith('/')
     );
   }
   ```
   If an unsafe URL protocol (`javascript:`, `data:`) is detected, it is neutralized and rendered as plain text.
3. **Link Hardening:** Links render with `target="_blank" rel="noopener noreferrer"`, protecting against `window.opener` tabnabbing.
4. **Citation Resolution:** Inlined citation badges render within separate interactive React components ([citation-badge.tsx](file:///c:/Projects/kinergy-platform/apps/web/src/modules/intelligence/assistant/components/citation-badge.tsx)), opening modal previews verified by short-lived HMAC preview tokens.

## 8. Security Findings, Evidence, and Recommended Mitigations

### Finding SEC05-F01: Lack of Automated Post-Generation System Prompt Scrubber

- **Severity:** **LOW (CVSS: 3.3 - CVSS:3.1/AV:N/AC:L/PR:L/UI:N/S:U/C:L/I:N/A:N)**
- **Affected File:** [grounded-generation.service.ts](file:///c:/Projects/kinergy-platform/apps/api/src/ai/services/rag/grounded-generation.service.ts#L123-L165).
- **Issue:** While Rule 9 in the system prompt instructs the model never to disclose internal prompts, the output processing pipeline lacks a deterministic post-generation filter scanning `answer` for system prompt fragments or developer instructions.
- **Impact:** An attacker who successfully crafts a sophisticated jailbreak could potentially extract the system prompt instructions.
- **Remediation:** Implement a lightweight post-generation string/token similarity filter in `GroundedGenerationService` that verifies `answer` does not contain verbatim sequences from `KINERGY_RAG_PROMPT_VERSION`.

---

### Finding SEC05-F02: Unrestricted External Hyperlink Rendering in Web Client

- **Severity:** **MEDIUM (CVSS: 4.3 - CVSS:3.1/AV:N/AC:L/PR:N/UI:R/S:U/C:N/I:L/A:N)**
- **Affected File:** [markdown-renderer.tsx](file:///c:/Projects/kinergy-platform/apps/web/src/modules/intelligence/assistant/components/markdown-renderer.tsx#L14-L29).
- **Issue:** `isSafeUrl()` permits all `http://` and `https://` URLs without domain allowlisting.
- **Impact:** If an attacker ingests a malicious document containing phishing links (e.g. `[Actualización de Protocolo](https://phishing-portal.com)`), the LLM can reproduce the link in its answer. When rendered, users may click the external link under the assumption that it was vetted by Kinergy.
- **Remediation:**
  1. Add an external link interstitial confirmation modal (e.g. _"You are leaving Kinergy to visit an external website"_).
  2. Implement an optional trusted domain allowlist for clinical and partner resources.

---

### Finding SEC05-F03: Unescaped Markdown Section Delimiters in Retrieved Evidence

- **Severity:** **LOW (CVSS: 2.6 - CVSS:3.1/AV:N/AC:H/PR:L/UI:N/S:U/C:N/I:L/A:N)**
- **Affected File:** [rag-context-builder.service.ts](file:///c:/Projects/kinergy-platform/apps/api/src/ai/services/rag/rag-context-builder.service.ts#L198-L208).
- **Issue:** `escapeUntrustedContent()` escapes XML tags (`</evidence_chunk>`, `<system>`), but does not escape or indent Markdown heading markers (`### USER INQUIRY:`, `### CONVERSATION HISTORY:`).
- **Impact:** A document containing `### USER INQUIRY:` could cause minor structural ambiguity in models that rely heavily on Markdown headers for prompt parsing.
- **Remediation:** Add indentation (2 spaces) to evidence chunk contents or prefix lines starting with `###` inside chunks with `\###`.
