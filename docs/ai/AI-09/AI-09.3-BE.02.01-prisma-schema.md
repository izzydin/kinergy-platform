## 1. Executive Summary

This deliverable establishes the relational Prisma schema foundation for AI conversation persistence in accordance with the approved architecture (**AI-09.3-BE.01.8**).

All four required persistence entities (`AiConversation`, `AiConversationTurn`, `AiConversationMessage`, `AiConversationAuditLog`) and three persistence enums (`ConversationRole`, `GenerationStatus`, `TurnStatus`) are defined in `prisma/schema.prisma`. All composite foreign keys, tenant ownership guarantees, and Prisma-level constraints are validated and active.

## 2. Entities & Enums Implemented

### 2.1 Prisma Enums

- **`ConversationRole`:**
  - `USER`: End-user prompt author.
  - `ASSISTANT`: Model response or generation attempt.
  - `SYSTEM`: System prompt injection or boundary instruction.
- **`TurnStatus`:**
  - `PENDING`: Turn created, awaiting or beginning initial generation.
  - `STREAMING`: Active assistant attempt currently streaming tokens.
  - `COMPLETED`: Turn reached a terminal canonical success state.
  - `FAILED`: Turn execution failed.
  - `CANCELLED`: Client explicitly aborted the turn.
  - `INTERRUPTED`: Turn dropped or socket disconnected before completion.
- **`GenerationStatus`:**
  - `PENDING`: Generation attempt initialized, lease acquired.
  - `STREAMING`: Model generating tokens.
  - `SUCCESS`: Generation successfully finished and verified.
  - `FAILED`: Model or pipeline produced an error.
  - `CANCELLED`: Generation cancelled by client abort.
  - `INTERRUPTED`: Generation disconnected or timed out.

## 3. Relationship Definitions & Composite Referential Integrity

To enforce cross-tenant and cross-conversation isolation at the database level, composite foreign keys are defined:

1. **Turn $\to$ Conversation:**

   ```prisma
   conversation AiConversation @relation(fields: [conversationId, tenantId], references: [id, tenantId], onDelete: Cascade)
   ```

   _Constraint:_ Turn must belong to the exact tenant that owns the conversation.

2. **Message $\to$ Conversation:**

   ```prisma
   conversation AiConversation @relation(fields: [conversationId, tenantId], references: [id, tenantId], onDelete: Cascade)
   ```

   _Constraint:_ Message must belong to the exact tenant that owns the parent conversation.

3. **Message $\to$ Turn:**

   ```prisma
   turn AiConversationTurn @relation("TurnAllMessages", fields: [turnId, conversationId, tenantId], references: [id, conversationId, tenantId], onDelete: Cascade)
   ```

   _Constraint:_ Message must belong to the exact turn, conversation, and tenant simultaneously.

4. **Turn Active Attempt Pointer:**

   ```prisma
   activeAttempt AiConversationMessage? @relation("TurnActiveAttempt", fields: [activeAttemptId], references: [id], onDelete: SetNull)
   ```

   _Note:_ Safe circular reference handling with `onDelete: SetNull`. Cross-turn integrity and single-attempt guarantees are reinforced via PostgreSQL partial unique index and validation triggers.

5. **Independent Audit Log Retention:**
   `AiConversationAuditLog` maintains intentional relational decoupling (no foreign key to `ai_conversations`), ensuring audit logs survive conversation soft or hard deletion.

## 5. Constraints Requiring PostgreSQL Migration SQL

Prisma schema cannot natively express partial unique indexes, check constraints, or mutation triggers. These are implemented and enforced via PostgreSQL migration SQL:

### 5.1 Partial Unique Indexes

1. **Single User Message Per Turn:**
   ```sql
   CREATE UNIQUE INDEX "uq_turn_single_user_message"
   ON "ai_conversation_messages"("turn_id")
   WHERE "role" = 'USER';
   ```
2. **Single Canonical Assistant Message Per Turn:**
   ```sql
   CREATE UNIQUE INDEX "uq_turn_single_canonical_assistant"
   ON "ai_conversation_messages"("turn_id")
   WHERE "role" = 'ASSISTANT' AND "is_canonical" = TRUE;
   ```
3. **Single Active Attempt Per Conversation:**
   ```sql
   CREATE UNIQUE INDEX "uq_conversation_single_active_attempt"
   ON "ai_conversation_turns"("conversation_id")
   WHERE "active_attempt_id" IS NOT NULL;
   ```

### 5.2 PostgreSQL Check Constraints

1. `chk_canonical_requires_success`: `"is_canonical" = FALSE OR ("role" = 'ASSISTANT' AND "status" = 'SUCCESS')`
2. `chk_terminal_attempt_no_lease`: `("status" NOT IN ('SUCCESS', 'FAILED', 'CANCELLED', 'INTERRUPTED')) OR ("lease_token" IS NULL AND "lease_expires_at" IS NULL)`
3. `chk_turn_index_positive`: `"turn_index" > 0`
4. `chk_sequence_number_positive`: `"sequence_number" > 0`
5. `chk_attempt_number_positive`: `"attempt_number" > 0`
6. `chk_active_attempt_number_positive`: `"active_attempt_number" > 0`

### 5.3 PostgreSQL Integrity Triggers

1. **`trg_validate_turn_active_attempt`:** Verifies that any non-null `active_attempt_id` on a turn references a message belonging to the exact same turn and having role `ASSISTANT`.
2. **`trg_protect_message_immutability`:** Prevents updates to `role`, `turn_id`, `conversation_id`, or `tenant_id` on existing messages.
