## 2. Verification of the 16 Mandatory Security Invariants

All 16 mandatory final security invariants specified in the acceptance criteria have been verified with direct evidence:

1. **Authentication & Authorization Required:**
   - Unauthenticated uploads reject with `401 Unauthorized`. Callers lacking `ai.documents.upload` reject with `403 Forbidden`. Callers attempting to assign management visibility scopes without clearance reject with `403 Forbidden`.
   - _Evidence:_ `ai-adversarial-file-security.integration.spec.ts` Tests A.1, A.2, A.3.

2. **File Size Constrained by Actual Received Bytes:**
   - Client metadata headers (`Content-Length`) are discarded. Validation asserts `buffer.length <= 10MB`. Files exceeding the limit reject with `413 Payload Too Large`.
   - _Evidence:_ `ai-adversarial-file-security.integration.spec.ts` Tests C.1, C.2, C.3.

3. **Content Signature Verification:**
   - Magic bytes (`%PDF-`, `PK\x03\x04`, UTF-8 byte stream) take absolute precedence over file extensions and client MIME headers. Executables, ELF binaries, and disguised media are halted before parser invocation.
   - _Evidence:_ `ai-adversarial-file-security.integration.spec.ts` Tests B.1, B.2, B.9.

4. **Client Filenames & MIME Untrusted:**
   - Filenames are treated as inert metadata labels. Double extensions (`.pdf.exe`) are evaluated by extracting true trailing extensions. Mismatched MIME declarations throw `DocumentContentMismatchException`.
   - _Evidence:_ `ai-adversarial-file-security.integration.spec.ts` Tests B.4, B.11.

5. **Internal Storage Identifiers Generated by Backend:**
   - Storage keys follow the deterministic synthetic pattern: `tenants/{tenantId}/knowledge_base/{year}/{month}/{uniqueId}-{uuid}.{ext}`. User filenames never touch physical storage paths.
   - _Evidence:_ `ai-adversarial-file-security.integration.spec.ts` Tests D.1, D.2, D.7.

6. **Path Traversal Neutralized:**
   - Traversal sequences (`../`, `..\\`, `%2e%2e%2f`), absolute paths (`C:\...`), and Windows reserved device names (`CON`, `PRN`, `AUX`) are sanitized to inert strings. Embedded null bytes (`\0`) are rejected immediately.
   - _Evidence:_ `ai-adversarial-file-security.integration.spec.ts` Tests D.1-D.5.

7. **Private Storage by Default:**
   - Object storage buckets have public access disabled. File downloads require either a 15-minute presigned S3 URL or an HMAC-SHA256 signed preview token binding user, tenant, document, and expiration.
   - _Evidence:_ `ai-storage-security.integration.spec.ts` & `ai-adversarial-file-security.integration.spec.ts` Test A.5.

8. **Temporary Scratch Files Protected & Cleaned:**
   - `TempFileStorageService` creates tenant-isolated scratch directories with POSIX permissions `0700` and files `0600`. Cleanup executes deterministically in `finally` blocks upon success, failure, or timeout.
   - _Evidence:_ `ai-adversarial-file-security.integration.spec.ts` Tests E.7, H.4.

9. **Approved Malware & Archive Policies Enforced:**
   - Buffers matching EICAR or suspicious macro signatures fail closed and are quarantined. The ClamAV daemon connection fails closed on `ECONNREFUSED`. DOCX zip bombs (>50MB, >1,000 entries, >100:1 ratio) and nested archives are rejected.
   - _Evidence:_ `ai-adversarial-file-security.integration.spec.ts` Tests E.1-E.6.

10. **Zero Execution of Uploaded Content as Code:**
    - Parsers run in pure JavaScript (`unpdf`, `mammoth`, `marked`). No shell interpreters (`eval()`, `child_process.exec`, `sh`, `cmd.exe`) are ever invoked.
    - _Evidence:_ `ai-parser-isolation.integration.spec.ts` Scenario 4.

11. **Parser Resource Bounds & Privileges Restricted:**
    - Enforces 30-second processing timeout and 5,000,000 character maximum extraction ceiling. Subprocesses execute with unprivileged user credentials (`USER node`) and `shell: false`.
    - _Evidence:_ `ai-adversarial-file-security.integration.spec.ts` Tests C.5, C.6, F.2, F.4.

12. **External Resource Resolution (SSRF / LFI / XXE) Blocked:**
    - Mammoth is configured with `externalFileAccess: false`, and image conversion is suppressed (`convertImage: () => ''`), preventing external network requests and local file inclusions.
    - _Evidence:_ `ai-parser-isolation.integration.spec.ts` Scenarios 5, 6, 7.

13. **Malformed Files Fail Safely:**
    - Truncated PDF streams, missing `%%EOF` markers, and corrupted ZIP central directories are caught gracefully and throw `DocumentMalformedException` without crashing the Node.js event loop.
    - _Evidence:_ `ai-adversarial-file-security.integration.spec.ts` Tests B.7, B.8, F.1.

14. **Failed / Quarantined Content Excluded from Retrieval:**
    - Documents in `UPLOADED`, `PROCESSING`, or `FAILED` states are invisible to semantic and lexical retrieval queries (`status = 'ACTIVE'`, `deleted_at IS NULL`, `kd.status = 'READY'`). Quarantined documents yield 0 queryable chunks.
    - _Evidence:_ `ai-adversarial-file-security.integration.spec.ts` Tests A.6, A.7, G.1, G.2.

15. **Diagnostic Sanitization & Anti-Enumeration:**
    - Error responses redact host filesystem paths, internal storage keys, database credentials, and virus names. Missing or cross-tenant lookups emit uniform 404 anti-enumeration responses.
    - _Evidence:_ `ai-adversarial-file-security.integration.spec.ts` Tests A.5, F.3, F.5.

16. **AI-10.1 & AI-10.2 Guarantees Preserved:**
    - All existing RBAC role-level permissions, document-level visibility scopes, document/chunk provenance bindings, and PostgreSQL isolation guarantees remain 100% operational.
    - _Evidence:_ Full passing suite of 97 regression tests across 6 authorization/isolation suites.
