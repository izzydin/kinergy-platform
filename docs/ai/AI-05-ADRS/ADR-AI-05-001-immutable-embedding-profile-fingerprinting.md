# ADR-AI-05-001: Immutable Embedding Profile & Cryptographic Fingerprinting

## Status

Accepted

## Context

In semantic retrieval and RAG architectures, vectors generated by different models, tokenizers, dimensionalities, pooling strategies, or normalization policies occupy incompatible geometric spaces. Calculating cosine similarity between vectors originating from different configurations (or silently mutated model weights) produces meaningless results or silent degradation of retrieval accuracy.

Furthermore, environment variables (e.g. `EMBEDDING_MODEL=bge-m3`) are mutable and cannot serve as durable audit trails or provenance markers for vectors persisted over months or years.

## Decision

1. Implement an immutable `EmbeddingProfile` Value Object encapsulating:
   - `provider`: Provider runtime name (e.g., `ollama`).
   - `modelName`: Canonical model identifier (e.g., `bge-m3`).
   - `modelVersion`: Version or tag (e.g., `latest`).
   - `modelDigest`: Cryptographic SHA-256 digest of the model weights / manifest.
   - `dimensions`: Exact integer dimension count (strictly 1,024 for BGE-M3 baseline).
   - `tokenizerIdentity`: Associated tokenizer (e.g., `xlm-roberta`).
   - `normalizationPolicy`: Vector normalization strategy (`UNIT_L2` or `NONE`).
   - `poolingStrategy`: Output token pooling (`CLS`, `MEAN`, `LAST_TOKEN`).
   - `embeddingType`: `DENSE`, `SPARSE`, or `HYBRID`.
2. Compute a deterministic canonical SHA-256 fingerprint for `profileId` formatted as:
   `prof_<modelName>_<dimensions>_<hash>`
3. Any change in model weights, digest, dimensionality, normalization, or pooling produces an entirely new profile. Profiles are never mutated in place.

## Consequences

### Positive

- Strict mathematical integrity: Vectors are tied to their exact geometric universe.
- Zero silent model drift: Changes in model weights are immediately detected and isolated.
- Auditability: Complete lineage and provenance from source chunk to vector representation.

### Negative / Trade-offs

- Upgrading an embedding model requires initiating a re-indexing generation rather than swapping an environment variable.
