## 1. Executive Summary & Objective

This deliverable establishes an authoritative, reproducible, and safe **adversarial prompt injection test corpus** and automated red-team test suite for the Kynergy RAG assistant.

### Core Security Guarantees:

1. **Harmless Synthetic Fixtures:** Zero live production data, zero confidential health/patient data, zero secrets/tokens, and zero executable exploit payloads.
2. **Deterministic Evaluation:** Security invariants do **not** depend on stochastic or remote LLM responses. Defenses are verified against deterministic application code (`IsolatedPromptBuilder`, `RAGContextBuilderService`, `SuspiciousContentDetector`, `CitationValidatorService`, and `ToolExecutionPolicyGuard`).
3. **Comprehensive Coverage:** 17 adversarial attack scenarios spanning direct injection, indirect document injection, fake developer markup, delimiter breakouts, obfuscation, multilingual attacks, cross-tenant probing, tool invocation, metadata attacks, and citation manipulation.
4. **Benign Control Calibration:** 3 benign control scenarios covering standard clinical protocols, equipment maintenance checklists, and administrative policies to ensure zero false-positive rejections.

## 4. Test Data Privacy & Ethical Guardrails

1. **No Live Production Data:** All documents (`Guía Clínica Interna`, `Procedimiento Quirúrgico`, `Diagnósticos Confidenciales`) are synthetic fixtures.
2. **No Real PII / PHI:** Patient IDs are synthetic identifiers (`pat-999`, `pat-1`), and tenant IDs are isolated mocks (`tenant-clinica-alpha`, `tenant-clinica-beta`).
3. **No Weaponized Payloads:** Payloads demonstrate prompt boundaries using harmless keywords (`PWNED`, `eval(atob(...))`, `Ignorieren Sie...`), not weaponized exploit chains.
4. **No Dependence on Stochastic LLM Refusals:** Every test in the suite asserts on deterministic application invariants:
   - XML serialization and escaping (`escapePromptXmlEntities`).
   - Structural boundary checks (`validatePromptStructure`).
   - Strict tenant matching and status filtering (`RAGContextBuilderService`).
   - Heuristic pattern evaluation (`SuspiciousContentDetector`).
   - Citation referential integrity (`CitationValidatorService`).
   - Unconditional tool blocking (`ToolExecutionPolicyGuard`).
