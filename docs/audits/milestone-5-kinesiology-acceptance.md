## 4. Documented Scope Exclusions & Backend Recommendations

### 1. External Therapist Licensing Eligibility Port DI (`ITherapistLookupPort`)

- **Root Cause**: In `KinesiologyModule`, `AssignTherapistToSessionHandler` currently accepts therapist UUIDs without performing runtime verification against an external Identity practitioner licensing registry adapter.
- **Impact**: While the session stores the reassigned therapist ID and emits `TreatmentSessionTherapistAssignedEvent`, verifying that the therapist is in good standing with active professional kinesiology licensure is not enforced at the database level.
- **Remediation**: Implement and bind an `IdentityTherapistLookupAdapter` in `KinesiologyModule` implementing `ITherapistLookupPort`.

### 2. Client Timeline Cross-Context Event Publishing (`DomainEventPublisher`)

- **Root Cause**: `CompleteTreatmentSessionHandler` handles session completion and persistence, but publishing the domain event to external event buses (such as the asynchronous `ClientTimelineProjectionHandler`) requires wiring the message bus provider in production environments.
- **Impact**: The treatment session itself is authoritatively completed and locked in PostgreSQL, but asynchronous timeline cards on the client overview rely on synchronous queries or subsequent projection triggers.
- **Remediation**: Wire the Outbox or Redis event publisher in the root NestJS application configuration.

### 3. Dedicated Medico-Legal Addendum / Amendment Endpoint

- **Root Cause**: Once a session is in `COMPLETED` status, the backend enforces strict immutability (`RECORD_LOCKED`). There is currently no dedicated `POST /sessions/:id/addendum` endpoint for signed post-completion corrections.
- **Impact**: Clinicians cannot append signed addenda to already sealed SOAP records. Any corrections require administrative intervention or documentation in a subsequent encounter.
- **Remediation**: Define an `AddSessionAddendumDto` and aggregate method allowing append-only audit addenda without altering the sealed original SOAP content.
