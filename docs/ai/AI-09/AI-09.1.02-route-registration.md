## 1. Executive Summary

Milestone **AI-09.1.02** registers the complete route hierarchy for the **Kynergy Intelligence** feature module within the existing platform routing architecture.

The implementation preserves all established routing conventions:

- **Authentication:** Unauthenticated users are redirected cleanly to `/auth/login` by `ProtectedRoute`.
- **Authorization & RBAC:** Role-based route gating is strictly enforced per **ADR-AI-09-04**, protecting Knowledge Center views while granting all staff access to the AI Assistant.
- **Lazy Loading & Performance:** Route components (`ChatPage`, `KnowledgePage`, `DocumentDetailPage`) are dynamically code-split with automatic transient retry (`lazyWithRetry`).
- **Layout Shell Integrity:** All views share the `IntelligenceLayout` shell within the authenticated `DashboardLayout` without shell duplication or window scroll bouncing.

## 2. Registered Route Hierarchy

The routing tree is mounted under prefix `/intelligence/*` via `moduleRegistry.register()` and `ProtectedRouter`:

```
/intelligence (module root)
├── [index]                                -> Redirects immediately to /intelligence/chat (302/replace)
├── /intelligence/chat                     -> AI Assistant Workspace (ChatPage)
│   └── /intelligence/chat/:conversationId -> Active conversation thread deep link (ChatPage)
└── [IntelligenceKnowledgeGuard] (Role-guarded: SUPER_ADMIN, ADMIN, OWNER, ENERGY_MANAGER)
    ├── /intelligence/knowledge            -> Knowledge Center Document Library (KnowledgePage)
    ├── /intelligence/knowledge/documents/:documentId -> Document version inspection (DocumentDetailPage)
    └── * (within module)                  -> NotFoundView (404)
```

## 3. Authentication & Authorization Integration

### 3.1 Authentication Boundary (`ProtectedRoute`)

- Module registration in `apps/web/src/modules/intelligence/routes/intelligence.router.tsx` specifies `isProtected: true`.
- In `ProtectedRouter` (`apps/web/src/app/routes/protected-router.tsx`), all protected modules are wrapped in `<ProtectedRoute />` and `<DashboardLayout />`.
- **Unauthenticated Users:** If an unauthenticated user navigates directly to `/intelligence/chat` or `/intelligence/knowledge`, `ProtectedRoute` intercepts the request and issues a clean client-side redirect to `/auth/login?redirect=<targetPath>`. No private data or layout shell is flashed.

### 3.2 Authorization Boundary (`IntelligenceKnowledgeGuard`)

- Source: `apps/web/src/modules/intelligence/routes/intelligence-knowledge-guard.tsx`.
- Enforces **ADR-AI-09-04 (Role-Based Intelligence Feature Gating)**:
  ```typescript
  export const KNOWLEDGE_ALLOWED_ROLES = ['SUPER_ADMIN', 'ADMIN', 'OWNER', 'ENERGY_MANAGER'];
  ```
- **Authorized Users (`ADMIN`, `SUPER_ADMIN`, `OWNER`, `ENERGY_MANAGER`):** Granted access to document library and version inspection views.
- **Restricted Users (e.g., `OPERATOR`, `COLLABORATOR`, `MEMBER`):** Denied access with standard `ForbiddenView` (403 Access Denied: _"Se requieren privilegios de administración o gestión de energía para acceder a la Base de Conocimiento"_).
- **Security Invariant:** Unauthorized authenticated users are **never** redirected to `/auth/login`; they remain in their authenticated session and receive the 403 boundary view within the layout.

## 4. Lazy Loading & Bundle Performance

To ensure the Intelligence module does not inflate initial bundle sizes for users browsing other features, route components are split into on-demand chunks:

```typescript
const ChatPage = lazyWithRetry(() =>
  import('../assistant/routes/chat-page').then((m) => ({ default: m.ChatPage })),
);
const KnowledgePage = lazyWithRetry(() =>
  import('../knowledge/routes/knowledge-page').then((m) => ({ default: m.KnowledgePage })),
);
const DocumentDetailPage = lazyWithRetry(() =>
  import('../knowledge/routes/document-detail-page').then((m) => ({
    default: m.DocumentDetailPage,
  })),
);
```

- **Resilience:** `lazyWithRetry` implements a single automatic 500ms retry upon chunk fetch failure, mitigating transient mobile network interruptions.
- **Loading State:** Wrapped in React `<Suspense fallback={<SuspenseFallback label="Cargando Kynergy Intelligence..." />}>` to eliminate layout shift during chunk resolution.
