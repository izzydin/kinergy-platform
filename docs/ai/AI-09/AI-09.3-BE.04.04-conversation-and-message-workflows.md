## 1. Executive Summary

This report documents the architectural design, implementation, and verification of the conversation retrieval, message history, title management, archiving, and message state persistence use cases under `packages/core/src/ai/application/use-cases/`.

These use cases complete the non-LLM application workflows for conversation lifecycle and message persistence in accordance with Clean Architecture principles:

1. **GetConversationUseCase:** Retrieves full conversation aggregates with tenant-scoped isolation, optional child turn summaries, and real-time active turn identification.
2. **ListConversationsUseCase:** Returns keyset-paginated (`(lastActivityAt DESC, id DESC)`) conversation summaries for navigation and history UI, with bounded page limits (default 20, max 100) and soft-deletion filtering.
3. **GetMessageHistoryUseCase:** Returns keyset-paginated (`(sequenceNumber ASC, id ASC)`) canonical message history for active chat workspaces, ensuring strict snapshot consistency without skipping or duplicating messages.
4. **UpdateConversationTitleUseCase:** Enforces domain-level title validation (`ConversationTitle`, 1–255 characters, non-empty), prevents updating archived conversations, and persists updated metadata.
5. **ArchiveConversationUseCase:** Safely soft-deletes (`deletedAt`) conversations while verifying that no generation is in progress (`TurnAlreadyInProgressError`), preventing duplicate archiving (`InvalidConversationLifecycleError`), and preserving audit logs independently.
6. **PersistMessageStateUseCase:** Safely mutates generation status, streaming output, completion timestamps, and canonical designations while enforcing sequence, identity, and role immutability (USER role remains strictly `SUCCESS` and non-canonical).

## 2. Implemented Use Cases & Architectural Contracts

### 2.1 GetConversationUseCase

- **Path:** `packages/core/src/ai/application/use-cases/get-conversation.use-case.ts`
- **Contract:**
  - Input: `GetConversationInput` (`tenantId`, `conversationId`, `includeTurns?: boolean`)
  - Output: `ConversationDetailDto`
- **Invariants & Guarantees:**
  - Enforces preflight input validation; rejects empty or whitespace-only tenant and conversation IDs with `InvalidTurnInputError`.
  - Enforces tenant isolation: queries `findById` with `(tenantId, conversationId)`. If not found, raises `ConversationNotFoundError(conversationId, tenantId)`. Cross-tenant leaks are strictly prohibited.
  - Efficiently delegates to `findByIdWithDetails` when available, fetching turns ordered by `turnIndex ASC` and dynamically resolving `activeTurnId` (pointing to any turn in `PENDING` or `STREAMING` status).

### 2.2 ListConversationsUseCase

- **Path:** `packages/core/src/ai/application/use-cases/list-conversations.use-case.ts`
- **Contract:**
  - Input: `ListConversationsInput` (`tenantId`, `userId`, `cursor?: string | null`, `limit?: number`, `includeArchived?: boolean`)
  - Output: `ListConversationsResult` (`items: ConversationSummaryDto[]`, `nextCursor: string | null`, `hasMore: boolean`)
- **Invariants & Guarantees:**
  - Clamps limit strictly between 1 and 100 (default: 20).
  - Uses keyset cursor pagination based on `(lastActivityAt DESC, id DESC)` via `ConversationListCursor`.
  - Filters out soft-deleted conversations (`deletedAt IS NULL`) by default unless `includeArchived: true` is explicitly requested.

### 2.3 GetMessageHistoryUseCase

- **Path:** `packages/core/src/ai/application/use-cases/get-message-history.use-case.ts`
- **Contract:**
  - Input: `GetMessageHistoryInput` (`tenantId`, `conversationId`, `cursor?: string | null`, `limit?: number`)
  - Output: `MessageHistoryResultDto` (`messages: MessageDto[]`, `nextCursor: string | null`, `hasMore: boolean`)
- **Invariants & Guarantees:**
  - Performs preflight tenant-scoped conversation existence check before querying message records.
  - Queries `messageRepo.listCanonicalHistory` using immutable sequence keyset pagination `(sequenceNumber ASC, id ASC)`.
  - Filters history strictly to `role = 'USER' OR is_canonical = true`, hiding failed, superseded, or orphan assistant attempts from the user chat workspace.

### 2.4 UpdateConversationTitleUseCase

- **Path:** `packages/core/src/ai/application/use-cases/update-conversation-title.use-case.ts`
- **Contract:**
  - Input: `UpdateConversationTitleInput` (`tenantId`, `conversationId`, `title: string`)
  - Output: `UpdateConversationTitleResult` (`conversationId: string`, `title: string`, `updatedAt: string`)
- **Invariants & Guarantees:**
  - Validates title syntax and length using domain value object `ConversationTitle.create(title)` (1 to 255 characters, trimmed).
  - Rejects title mutations on archived conversations with `InvalidConversationLifecycleError`.
  - Calls `convRepo.updateMetadata` or `conv.updateTitle() + save()`, updating `updatedAt` deterministically.

### 2.5 ArchiveConversationUseCase

- **Path:** `packages/core/src/ai/application/use-cases/archive-conversation.use-case.ts`
- **Contract:**
  - Input: `ArchiveConversationInput` (`tenantId`, `conversationId`)
  - Output: `ArchiveConversationResult` (`conversationId: string`, `isArchived: boolean`, `archivedAt: string`)
- **Invariants & Guarantees:**
  - Verifies conversation exists within the specified tenant boundary (`ConversationNotFoundError`).
  - Idempotency guard: Throws `InvalidConversationLifecycleError` if the conversation is already archived.
  - Active Generation Guard: Calls `turnRepo.findActiveTurn(tenantId, conversationId)`. If an active generation (`PENDING` or `STREAMING`) is in flight, archiving is refused with `TurnAlreadyInProgressError`.
  - Audit retention: Soft-deletes the conversation by timestamping `deletedAt = now()`. Relational foreign keys and `AiConversationAuditLog` records remain intact for clinical and administrative review.

### 2.6 PersistMessageStateUseCase

- **Path:** `packages/core/src/ai/application/use-cases/persist-message-state.use-case.ts`
- **Contract:**
  - Input: `PersistMessageStateInput` (`tenantId`, `conversationId`, `messageId`, `status`, `content?`, `isCanonical?`, `completedAt?`, `errorCode?`, `errorMessage?`)
  - Output: `PersistMessageStateResult`
- **Invariants & Guarantees:**
  - Message existence verified in tenant and conversation scope (`MessageNotFoundError`).
  - Identity & Sequence Immutability: `role`, `sequenceNumber`, `turnId`, `conversationId`, `tenantId`, and `attemptNumber` cannot be updated through this workflow.
  - USER Role Protection: USER messages must remain permanently in status `SUCCESS`, attempt number 1, and non-canonical. Any attempt to mark a user message as FAILED, STREAMING, or canonical throws `InvalidMessageOperationError`.
  - Canonical Invariant: Only successfully completed assistant messages (`status === GenerationStatus.SUCCESS`) can have `isCanonical === true`.

## 3. Keyset Pagination Strategy Comparison

| Dimension                | Conversation Listing (`ListConversationsUseCase`)                                                                       | Message History (`GetMessageHistoryUseCase`)                                                                                      |
| :----------------------- | :---------------------------------------------------------------------------------------------------------------------- | :-------------------------------------------------------------------------------------------------------------------------------- |
| **Ordering Tuple**       | `(lastActivityAt DESC, id DESC)`                                                                                        | `(sequenceNumber ASC, id ASC)`                                                                                                    |
| **Cursor Value Object**  | `ConversationListCursor` (`${ISO8601}_${id}`)                                                                           | `MessageHistoryCursor` (`${sequenceNumber}_${id}`)                                                                                |
| **Index Used**           | `ai_conversations_user_activity_idx`                                                                                    | `uq_conversation_msg_sequence` / `idx_canonical_history`                                                                          |
| **Snapshot Consistency** | **Eventual / Dynamic:** `lastActivityAt` updates when new turns occur; concurrent writes may shift items between pages. | **Strict Snapshot Consistent:** Monotonic sequence numbers are strictly immutable; pages are completely stable and deterministic. |
| **Bounded Limits**       | Clamped to `[1, 100]`, default 20                                                                                       | Clamped to `[1, 100]`, default 20                                                                                                 |
| **Filtering**            | `deletedAt IS NULL` (unless `includeArchived: true`)                                                                    | `role = 'USER' OR is_canonical = true`                                                                                            |
