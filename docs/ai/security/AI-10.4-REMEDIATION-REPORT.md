## 2. Detailed Technical Remediations

### A. Prompt & Context Boundary Isolation (`KY-PI-001`, `KY-PI-002`, `KY-PI-004`, `KY-PI-006`)

- **Implemented In:** [`packages/core/src/ai/domain/prompts/rag-prompt.template.ts`](file:///c:/Projects/kinergy-platform/packages/core/src/ai/domain/prompts/rag-prompt.template.ts) and [`apps/api/src/ai/services/rag/rag-context-builder.service.ts`](file:///c:/Projects/kinergy-platform/apps/api/src/ai/services/rag/rag-context-builder.service.ts).
- **Mechanism:**
  - `buildRAGUserPrompt` wraps the user query in `<user_query>` and all evidence chunks inside `<retrieved_evidence>`.
  - `escapePromptXmlEntities` converts `&`, `<`, `>`, `"`, `'` to XML entities, preventing any delimiter breakouts.
  - Chunk attributes (`doc_id`, `title`, `page`) are stripped of carriage returns (`\r`), line feeds (`\n`), and quotes.
  - `validatePromptStructure` deterministically audits assembled prompts before provider invocation.

### B. Pre-LLM Heuristic Screener (`KY-PI-003`)

- **Implemented In:** [`packages/core/src/ai/domain/services/suspicious-content-detector.service.ts`](file:///c:/Projects/kinergy-platform/packages/core/src/ai/domain/services/suspicious-content-detector.service.ts).
- **Mechanism:**
  - Evaluates retrieved chunk text against deterministic regex heuristics across 8 attack categories: `SYSTEM_OVERRIDE`, `PROMPT_EXTRACTION`, `UNAUTHORIZED_ACCESS`, `PRIVILEGED_ACTION`, `IDENTITY_HIJACK`, `ENCODED_PAYLOAD`, `DATA_EXFILTRATION`, and `CITATION_FORGERY`.
  - Includes multilingual override detection (German rule `SO-05`).
  - `RAGContextBuilderService` drops high-severity suspicious chunks from the LLM context pool before prompt construction.

### C. Output Sanitization & Exfiltration Defense (`KY-PI-005`)

- **Implemented In:** [`apps/api/src/ai/services/rag/citation-validator.service.ts`](file:///c:/Projects/kinergy-platform/apps/api/src/ai/services/rag/citation-validator.service.ts).
- **Mechanism:**
  - Added Check 4G to `CitationValidatorService.validateResponse`.
  - Scans model answers for Markdown image exfiltration URLs (`![...](https://...)`), raw HTML `<img>` tags, and `<script>` tags.
  - Sanitizes the answer to `[Image Removed: Exfiltration Prevention]`, removes script tags, and records an inconsistency audit event.

### D. Strict Read-Only Tool Safety & Decoupled Execution (`KY-SEC-TOOL`)

- **Implemented In:** [`packages/core/src/ai/domain/services/tool-execution-policy.guard.ts`](file:///c:/Projects/kinergy-platform/packages/core/src/ai/domain/services/tool-execution-policy.guard.ts).
- **Mechanism:**
  - Complete capability inventory classifies all business actions (`issue_refund`, `create_sale`, `update_patient_record`, `cancel_membership`, `delete_user`, `execute_shell`) as prohibited in the initial assistant.
  - `assertToolExecutionAllowed` unconditionally throws `ToolExecutionProhibitedException`.
  - `inspectPayloadForProhibitedToolInvocation` blocks hidden function calling payloads.
  - `validateToolArguments` rejects prototype pollution (`__proto__`, `constructor`, `prototype`) and payloads > 5,000 characters.
  - Physical decoupling: `AIModule` has zero dependency injection with mutation services.

### E. Tenant Boundary Enforcement (`KY-SEC-AUTH`)

- **Implemented In:** [`apps/api/src/ai/services/rag/rag-context-builder.service.ts`](file:///c:/Projects/kinergy-platform/apps/api/src/ai/services/rag/rag-context-builder.service.ts).
- **Mechanism:**
  - Chunks with mismatching `tenantId` are dropped unconditionally during context normalization.
  - Chunks with status `ARCHIVED`, `FAILED`, `QUARANTINED`, `DELETED`, or `PROCESSING` are rejected prior to candidate budgeting.

## 3. Boundary Regression Verification

A dedicated boundary regression suite was implemented in [`prompt-injection-remediation-regression.spec.ts`](file:///c:/Projects/kinergy-platform/apps/api/src/ai/services/rag/__tests__/prompt-injection-remediation-regression.spec.ts).

### Verified Integration Boundaries:

1. **Retrieval to Context Assembly:** Chunks containing `[SYSTEM OVERRIDE]` are dropped; attribute newlines sanitized.
2. **Context Assembly to Provider Adapter:** Closing XML tags in raw query are escaped; conversation history structured in `<conversation_turn>`.
3. **Model Tool Request to Application Execution:** State-changing mutation tools throw `ToolExecutionProhibitedException`.
4. **Authenticated Request to Authorized Retrieval:** Cross-tenant chunks (`tenant-clinica-beta`) dropped for `tenant-clinica-alpha`.
5. **Model Output to Client Delivery:** Markdown image exfiltration links stripped from `adjustedAnswer`.

## 5. Deployment Requirements & Assumptions

1. **No External Security Dependency:**  
   All implemented remediations run entirely in-process using TypeScript application logic. No proprietary external WAF, commercial prompt guard API, or sidecar daemon is required.
2. **Environment Variables:**  
   No new mandatory environment variables are introduced. Standard `AI_LLM_PROVIDER`, `AI_CHAT_MODEL` (`qwen3:4b`), and `AI_OLLAMA_BASE_URL` settings remain fully supported.
3. **Database Migrations:**  
   Zero database schema changes or migrations were required. All invariants operate on existing metadata columns (`tenantId`, `status`, `visibilityScope`, `deletedAt`).
4. **Logging Safety:**  
   No raw prompts, confidential documents, or patient health information are written to logs. Telemetry continues to record pseudonymous hashes and lengths via `GenerationObservabilityService`.
